# Inchly 紹介サイト

参考にした piixpal（https://piixpal.dvkk.dev/）に大胆に寄せて作った、Inchly の紹介ページです。
ふつうの HTML・CSS・JavaScript だけで、組み立ての手順はいりません。

- 参考サイトを言語化した文書：[`docs/site/piixpal-のすべて.md`](../docs/site/piixpal-のすべて.md)
- Inchly への当てはめ方：[`docs/site/inchly-サイトの設計.md`](../docs/site/inchly-サイトの設計.md)

## 手元で見る

```bash
cd site
python3 -m http.server 8000
```

ブラウザで http://localhost:8000 を開きます。

## ファイル

| ファイル | 中身 |
| --- | --- |
| `index.html` | ページの中身（文章はすべてここ） |
| `css/site.css` | 見た目（白・紙・暗いの3つのテーマ、スマホの並び） |
| `js/pix.js` | 住人（えんぴつのペンタ、炎のボッ、芽のめぶ、目ざましのジリ、ノートのふせん、折り鶴のつる）、科目の顔、みんなの舞台 |
| `js/site.js` | 大きなドットの「inchly」、テーマの切り替え、遊びのカード、使い方のタイマー、定規、フッターの草 |
| `img/` | アプリの画面写真（見本の人数と広告は消してある）と部品の切り抜き |

## 公開の前に埋めるところ

ページの中に、次の仮置きが残っています。

- [公開日]
- [Android版の予定]
- [連絡先]
- [年] [運営者名]

プライバシーポリシーと利用規約も、公開までに用意します。

## 決まり

- piixpal のキャラクター・ロゴ・文章は使っていません。住人と絵はすべて Inchly のために描いたものです。
- 動きを減らす設定（iPhone の「視差効果を減らす」など）では、住人も大きなロゴも止まります。フッターの「動きを止める」でも止められます。

# Inchly 紹介サイト

Inchly の紹介ページです。ページ全体が、中高生の「放課後から夜まで」の一日になっています。
学校の時間割（6限まで）の続きを Inchly が受け持ち、スクロールすると夕方から夜へ進みます。
骨組み（紙とインク、太い線、ぼかしのない影、押すと沈むボタン）は参考にした piixpal（https://piixpal.dvkk.dev/）から、
芯は Inchly だけのもの、という考えで作っています。
ふつうの HTML・CSS・JavaScript だけで、組み立ての手順はいりません。

- 参考サイトを言語化した文書：[`docs/site/piixpal-のすべて.md`](../docs/site/piixpal-のすべて.md)
- 4つの案のモックと審査の結果：[`docs/site/mocks/`](../docs/site/mocks/)（この形は「放課後から夜まで」の2版）

## 手元で見る

```bash
cd site
python3 -m http.server 8000
```

ブラウザで http://localhost:8000 を開きます。

## ファイル

| ファイル | 中身 |
| --- | --- |
| `index.html` | ページのすべて（文章・見た目・動き。CSS と JS も中にある） |
| `js/pix.js` | 住人（折り鶴のつる、炎のボッ など）の絵と動き |
| `img/` | アプリの画面写真（見本の人数と広告は消してある）と部品の切り抜き、アイコン |
| `favicon.svg` | タブのアイコン |

## さわれるところ

- 15:30〜17:00：学校の時間割から、Inchly の時間割へ
- 「勉強を開始」（ページに1か所）：見本のタイマーが早送り（1秒で3分）で進む
- 記録すると、今日の塔に科目の色のブロックが1段のる。3時間で「目標の3時間に、届いた」
- 7日の塔：横から／真上から（真上から見ると草のマス）
- アプリの画面は押すと大きく見られる
- フッターは26週の塔の町並み（高さ＝その週の勉強時間、合計664時間）

## 決まり

- piixpal のキャラクター・ロゴ・文章は使っていません。住人と絵はすべて Inchly のために描いたものです。
- データのグラフ（塔・町並み）は科目の色だけで、緑は使いません。
- 動きを減らす設定（iPhone の「視差効果を減らす」など）では、動きが止まります。

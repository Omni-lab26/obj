# UI の確認リスト

テーマ作り・背景作りの前に、標準のデザイン（スタンダード）の画面を1つずつ確かめて直していくための一覧です。

## 進め方

1. 1回に1つのまとまり（下の ① 〜 ⑮）を進めます。
2. Claude が報告します。各項目の画面写真（iPhone の幅、サンプルのアカウントと、はじめて使う人の両方）と、自分で見つけた気になる点を出します。
3. iPhone の Expo Go で確かめて、直してほしいことを項目の記号で伝えてください（例：「H4 の数字をもっと大きく」）。
4. 直してプッシュしたら、この表の状態を「済」にします。

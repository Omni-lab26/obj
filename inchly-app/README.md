# Inchly（Expo アプリ）

勉強時間を草として積み上げ、仲間と一緒に勉強する学習コミュニティアプリのモック実装です。
Expo SDK 57 / Expo Router / React Native。App Store 版の Expo Go が対応している SDK に合わせています。
記録・ToDo・締切・設定はこの端末に保存され、アプリを閉じても残ります。サーバーにはつながっていません（同期はモック）。
ほかの人・投稿・ランキングはサンプルです。

「測る・見える・一緒に・次」の4つを核にしたピボットの内容は [`docs/design/pivot.md`](../docs/design/pivot.md) にあります。

## スマホで見る（Expo Go）

1. スマホに **Expo Go** を入れる（App Store / Google Play）。
2. パソコンに Node.js（20 以上）を入れて、このフォルダで:

   ```bash
   cd inchly-app
   npm install
   npx expo start
   ```

3. ターミナルに出る QR コードを読み取る。
   - iPhone: 標準のカメラで読み取る → Expo Go で開く
   - Android: Expo Go の「Scan QR code」で読み取る

   パソコンとスマホは同じ Wi-Fi につないでください。会社や学校の Wi-Fi などでつながらないときは
   `npx expo start --tunnel` を試してください（初回は Expo アカウントへのログインを求められます）。

ブラウザで見るだけなら `npx expo start --web`。

### 「Project is incompatible with this version of Expo Go」と出たら

Expo Go が対応する SDK とプロジェクトの SDK（いまは 57）が合っていません。まず App Store / Google Play で Expo Go を最新にしてください。
それでも出る場合は、Expo Go の対応 SDK が上がっています。このフォルダで `npx expo install expo@latest --fix` を実行すると、プロジェクトもその SDK に上がります。

## 画面

ゲームのロビーのように、上に自分・レベル・コイン・お知らせ・設定のバー（`src/ui/Hud.tsx`）、
その下を左右にスワイプして5つのページを行き来します。真ん中がホーム（`src/app/(tabs)/_layout.tsx`）。

| ページ / 画面 | ファイル |
| --- | --- |
| はじめての起動（サインイン・年齢の確認・目標・通知） | `src/app/welcome.tsx` |
| ストア（コインで交換・今日のおすすめ・今日のミッション） | `src/app/(tabs)/store.tsx` |
| バッジ（44種・レア度・あと少しのバッジ）／グラフ | `src/app/(tabs)/collection.tsx`（バッジの計算は `src/lib/badges.ts`） |
| ホーム（カード・連続記録・今日／今週の勉強時間・ToDo） | `src/app/(tabs)/index.tsx`（グラフのカードは `src/ui/StudyChart.tsx`） |
| コミュニティ（勉強中・タイムライン・ランキング・グループ） | `src/app/(tabs)/community.tsx` |
| 右端（イベント／模試・締切／マイページから選ぶ） | `src/app/(tabs)/extra.tsx`（イベントは `src/lib/events.ts`） |
| マイページ（カード・成長・記録・投稿） | `src/app/me.tsx`（中身は `src/ui/MePage.tsx`） |
| 横向きの勉強部屋 | `src/ui/StudyRoom.tsx` |
| フォロー／フォロワー（マイページの数字から） | `src/app/follows.tsx` |
| タイマー | `src/app/timer.tsx` |
| グループ（チャット・イベント・共有） | `src/app/group/[id].tsx` |
| グループを作る / イベントを企画 | `src/app/create-group.tsx` / `src/app/plan-event.tsx` |
| お知らせ / さがす | `src/app/notifications.tsx` / `src/app/search.tsx` |
| 設定（ホーム右上の歯車から。公開範囲・メッセージ・通知・ブロック・データ） | `src/app/settings.tsx` |

日付・記録の集計・リマインダーなどの計算は `src/lib/`（テストは `src/lib/__tests__/`、`npm test`）。
共通部品は `src/ui/`、色・文字サイズ・影・動きの定数は `src/theme.ts`、サンプルデータは `src/data.ts`、
状態（タイマー・記録・ToDo・締切・設定）と端末への保存は `src/store.ts`、
記録・ToDo・締切・人の操作のシートは `src/ui/Editors.tsx` にあります。

はじめて開くとサインインの画面になります。「サンプルのアカウントで見る」で、すぐに中身を見られます。
最初からやり直すときは 設定 › アカウントとデータを削除。

## デザイン

- **フォント**: Apple のシステムフォント（英数字は SF Pro、日本語はヒラギノ角ゴ）。iPhone では何も読み込まずにそのまま使い、
  20pt 以上は SF Pro Display、それ未満は SF Pro Text に切り替わります。数字は等幅（tabular）で、カウンターが揺れません。
  Android では Roboto になります。
- **配色**: うすい青みのグレーの地に白いカード、文字とメインのボタンは紺に近い黒。緑は勉強と「増えた」数字、青は操作、
  オレンジ・赤は締切と足りない分。科目の色はグラフや小さな点にだけ使います（`src/theme.ts` / `src/data.ts`）。
- **大きさ**: ひとつの画面で大きいのは数字ひとつだけ（32pt）。カードの数字は 24pt、見出し 15pt、本文 14pt、補足 11〜12pt。
  線は細く（髪の毛線）、角丸は 16 / 12 で統一。小さなボタンも押せる範囲は 44pt 以上あります。
- **スタンプ**: `src/ui/Sticker.tsx`。はっきりした色、太い白フチ、やわらかい影のポップなシール。
  グループのチャット（下のハートからスタンプを送れる）、お知らせ、「役に立った」、記録したときのスタンプ、ランキングの上位などで使っています。

## 操作のポイント

- ホーム: 左上がカード（押すとマイページ）、右がスタートボタン（勉強中はタイマー）。その下に連続記録、勉強時間のグラフ、ToDo
- 勉強時間のカード: 「日」は今日を1時間ごとの24本、「週」は今週の月〜日の7本の縦棒。棒を押すとその時間の内訳が出る。
  右上の歯車でグラフの種類（科目別・棒・折れ線）と色（インク・ブルー・オレンジ・グレープ）を変えられる。勉強中の分は薄い色で上に積む。
  1回の記録は「終わった時刻」と「長さ」から、どの時間帯に勉強したかを割り出す（0時をまたいだ分は前の日に入る）
- スマホを横にすると勉強部屋になる（Apple Music のような専用の画面）。左に自分のタイマー、右にいま勉強中の人たち。縦に戻すと記録できる
- 全体の設定はホーム右上（上のバー）の歯車から
- 勉強1分で1コイン。ミッション（ストア）とイベント（右端のページ）でもらえる。ストアで休み券・コイン2倍などと交換

- 下のバーは浮いたガラス。選んでいるページだけ名前が出て、ホームは勉強中なら「● N分」になる
- マイページ: クレジットカードと同じ比率のカードの下に、データを4ページに分けたタブ（上に張り付く）。成長（グラフのカードは横にスワイプで「これまでの伸び → この7日間 → 科目の内訳 → 草」と1枚ずつ切り替わる（長く引いても1枚、カクッと止まる）。その下に昨日・先週・先月との比較、バッジ）／記録（今日の記録と半年の草）／グラフ（日・週の棒グラフ、科目、偏差値）／投稿
- フォロー・フォロワーは、マイページの数字を押すと一覧が開く
- タイムライン: 右下の＋で投稿。今日の記録をつけて投稿できる
- みんな › いま勉強中: 絞り込みの最後の＋で、志望校の絞り込みを足したり、人をさがしてフォローしたりできる
- 今日の合計とバーは、1回ずつの記録から計算する。記録タブの「今日の記録」で押すと直せる／消せる、「手で追加」で今日・昨日の分を足せる
- ホームの ToDo: ＋追加、右の「…」（または長押し）で編集・上下に並べ替え・削除。締切にひも付けると締切の進み具合に数える
- 締切（右端のページで「模試・締切」を選ぶ）: ＋追加、押すと削除。残り日数は今日から計算
- 記録するとき「どのToDoを進めた？」で選んだToDoは完了になる
- 人の名前やアイコン（勉強中・ランキング・投稿・チャット）を押すと、フォロー・ブロック・通報ができる。ブロックした人はどこにも出ない
- 18歳未満は、勉強中はフォロワーだけに見え、メッセージはフォロー中の人からだけ届く設定で始まり、「全員」は選べない
- 黒い「日連続」のカプセルを押すと炎がはねる
- グループのチャットでは、入力欄の左のハートでスタンプを選べる
- タイマーは右へスライドすると一時停止して「この勉強を記録」の画面へ。時間を5分ずつ直す、今日の合計がどう変わるか、進めたToDo、メモ、次はいつやるかを1画面で決めて記録する
- 記録の棒グラフ（bencho の stacked bars）: なぞると1本が囲まれてほかが薄くなり、内訳が横に出る。日／週で伸び直す。赤は目標に足りなかった分
- 偏差値のカード: 線をなぞるとその週の日付と値が小さなタグで出る。3か月／半年／1年で切り替え
- タイマー: 目盛りは「時間」と「分」の2本で、合計は最大5:00。ドラッグ・はじいて残り時間を決める（分は5分ごとに止まる）。動きはすべてUIスレッドで、指に遅れずに動く
- 数字（bencho の rolling counter）: 桁ごとに回って少し行き過ぎて止まる。定員の ＋／− は長押しで加速、数字を上下にドラッグしてもはじける
- 草は指で押したままなぞると、その日の時間が出る
- お知らせは右スワイプで既読、左スワイプで削除（元に戻せる）
- 上から出る通知は、重なっているところを押すと広がる
- 大学検索で2校以上チェックすると、比較のトレイが出る

## Expo Go で動かない機能について

ロック画面や iPhone の Dynamic Island に勉強時間を出す機能（Live Activities）は、Expo Go では作れません。
開発ビルド（`eas build --profile development`）が必要なので、このモックではタブの真ん中のボタンと、ホームの「勉強中」の行で代わりにしています。

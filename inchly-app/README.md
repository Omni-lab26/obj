# Inchly（Expo アプリ）

時間を管理したい人のためのアプリのモック実装です。使った時間を草として積み上げ、仲間と一緒に続けられます（画面の言葉は、いまは「勉強」で統一しています）。
Expo SDK 58 / Expo Router / React Native。App Store 版の Expo Go が対応している SDK に合わせています。
記録・ToDo・締切・設定はこの端末に保存され、アプリを閉じても残ります。サーバーにはつながっていません（同期はモック）。
ほかの人・投稿・ランキングはサンプルです。

「測る・見える・一緒に・次」の4つを核にしたピボットの内容は [`docs/design/pivot.md`](../docs/design/pivot.md) にあります。

## スマホで見る（Expo Go）

1. スマホに **Expo Go** を入れる（App Store / Google Play）。
2. パソコンに Node.js（20 以上）を入れて、このフォルダで:

   ```bash
   cd inchly-app
   npm install
   npx expo start
   ```

3. ターミナルに出る QR コードを読み取る。
   - iPhone: 標準のカメラで読み取る → Expo Go で開く
   - Android: Expo Go の「Scan QR code」で読み取る

   パソコンとスマホは同じ Wi-Fi につないでください。会社や学校の Wi-Fi などでつながらないときは
   `npx expo start --tunnel` を試してください（初回は Expo アカウントへのログインを求められます）。

ブラウザで見るだけなら `npx expo start --web`。

### 最新の変更を自動で取り込む（`npm run live`）

`npx expo start` の代わりに次を使うと、このブランチに push された変更を20秒ごとに取り込みます。
Metro が変更に気づくので、Expo Go は勝手に更新されます（変わらないときはスマホを振って Reload）。

```bash
cd inchly-app
git checkout claude/loving-cannon-adjszv   # 変更が push されるブランチ
npm install
npm run live              # 同じ Wi-Fi でないときは npm run live -- --tunnel
```

- パッケージや app.json が変わったときは、自動で `npm install` して Expo を立ち上げ直します（QRコードは同じ。Expo Go で開き直してください）。
- このフォルダのファイルを手で書き換えていると、取り込みを止めて知らせます（`git status` で確認）。
- パソコンを閉じると止まります。

### 「Project is incompatible with this version of Expo Go」と出たら

Expo Go が対応する SDK とプロジェクトの SDK（いまは 58）が合っていません。まず App Store / Google Play で Expo Go を最新にしてください。
それでも出る場合は、Expo Go の対応 SDK が上がっています。このフォルダで `npx expo install expo@latest --fix` を実行すると、プロジェクトもその SDK に上がります。

## デザイン

アプリの地は、やわらかい灰色（`#ECEDF0`）に、上から光がさすような白いもや（`Chrome.Screen` の `Haze`）。少し透けて見えるような軽さにしている。背景（鯉の池など）を選ぶと、地の代わりにそれがすべてのページのうしろで動き、カードはすりガラスになる（下の「背景」）。

- **科目の絵**: 科目は頭文字ではなく絵で出す（`src/ui/SubjectGlyph.tsx`）。化学＝フラスコ、物理＝原子、生物＝葉、地学＝山、数学＝π、英語＝吹き出しのA（リスニング＝ヘッドホン、英作文＝ペン）、国語＝開いた本（古文＝巻物、漢文＝筆）、世界史＝神殿、日本史＝鳥居、地理＝地図、政経・公共・倫理＝天秤、情報＝ノートパソコン。科目名から、なければ教科から決まり、どれにも当たらない科目は頭文字のまま。勉強バー・ホーム・科目と色・記録・タイマーのカードの表紙（大きく、うっすら）に出る
- **アプリのアイコン**: 左上のロゴと同じ、高さの上がっていく5本の目盛りを白地に。色は1本ずつ 赤 `#E5484D`・黄 `#F2C46D`・水色 `#9AB8DB`・青 `#5B8DEF`・紫 `#9D7BF5`（参考にした積み上げグラフの5色。`src/ui/Brand.tsx` の `BRAND_TICKS`）。`assets/images/` の `icon.png`・Android の3枚（白い背景・目盛り・単色）・`splash-icon.png`・`favicon.png`

- **フォント**: Apple のシステムフォント（英数字は SF Pro、日本語はヒラギノ角ゴ）。iPhone では何も読み込まずにそのまま使い、
  20pt 以上は SF Pro Display、それ未満は SF Pro Text に切り替わります。数字は等幅（tabular）で、カウンターが揺れません。
  Android では Roboto になります。
- **配色**: うすい青みのグレーの地に白いカード、文字とメインのボタンは紺に近い黒。緑は勉強と「増えた」数字、青は操作、
  オレンジ・赤は締切と足りない分。科目の色はグラフや小さな点にだけ使います（`src/theme.ts` / `src/data.ts`）。
- **大きさ**: ひとつの画面で大きいのは数字ひとつだけ（32pt）。カードの数字は 24pt、見出し 15pt、本文 14pt、補足 11〜12pt。
  線は細く（髪の毛線）、角丸は 16 / 12 で統一。小さなボタンも押せる範囲は 44pt 以上あります。
- **スタンプ**: `src/ui/Sticker.tsx`。はっきりした色、太い白フチ、やわらかい影のポップなシール。
  グループのチャット（下のハートからスタンプを送れる）、お知らせ、「役に立った」、記録したときのスタンプ、ランキングの上位などで使っています。

## テーマの仕組み（テーマ＝ひとつのアプリ）

**テーマと背景は別のもの。** テーマ（このページの仕組み）は見た目まるごと。背景（鯉の池・サメの海・歩く人）は、すべてのページとタイマーのうしろで動くもので、いまはスタンダードのテーマのときだけ出る（下の「背景」）。テーマの着せ替えは `src/design.ts` の `THEMES_OPEN` で隠せる（`false` にすると全員がスタンダードになり、選んだテーマは保存されたまま残る。背景はそのまま）。

## 背景（すべてのページのうしろ）

- 選べるのは 鯉の池（ふつう）・サメの海・歩く人・なし。横のメニューの「背景」、タイマー左上の「背景」、デザインのページの「背景」から（`src/ui/BackdropSheet.tsx`）。保存はデザインの `backdrop`。スタンダード以外のテーマでは出ない（`backdropOf`。背景を選ぶとスタンダードに戻る）。「なし」は地の色のままで、タイマーは科目の色に染まる。シートの右上は「保存」の ✓（青い丸）
- 動かすのは1か所だけ: ルートの `BackdropEngine` が鯉（サメ・人）を画面のスレッドで1秒に30回動かし、絵（SkPicture）に描く。各ページ（`Screen`）・横のメニュー・タイマーは、その絵を貼るだけ（`BackdropView`）。絵は2種類で、いま誰かが見せているものだけを描く（`src/ui/backdrop/shared.ts`）：
  - やわらかい絵（ページのうしろ）: 鯉1匹を体に沿った丸い形18個で、その色のまま描き、描くときにぼかす（Skia のぼかした円は GPU で軽い）。マス目の計算はしない。1コマ数百の数だけ
  - モザイク（タイマー・眺める・背景のぼかしが「なし」のページ）: 何千マスの計算がいちばん重いので、1秒に15回
  - 画面に指がふれている間と、離して少しのあいだ（スクロールのすべり・シートが止まるまで）は、背景を止める（`holdBackdrop`。ルートの `_layout` が指の動きを見ている）。計算も描画もしないので、操作中のコマはぜんぶ操作のもの
  - 前は、ページごとに画面全体をライブでぼかし（すりガラス）、裏ではずっとモザイクを1秒24回計算していて、背景をつけると全体がもっさりしていたどのページでも同じ鯉で、ページがいくつ開いていても計算は1回。見えていないページは描かない（`src/ui/backdrop/live.ts`: 前に出ているあいだと、離れてから少しのあいだ。タイマーを下に引くと、その下のページがまた描く）
- 白が基調: どの背景も淡い色（鯉の池は白に近い水、サメの海、ガラスの床）で、ページは明るいまま（濃い文字に白いガラスのカード。`src/theme.ts` の `OVER`）。淡い水でも鯉の白が見えるよう、鯉のまわりの記号は少し濃く、蓮の葉はやわらかい緑
- 背景とページのあいだに、白い膜を1枚（`src/ui/backdrop/Veil.tsx`）: ぼかしの強さは「背景のぼかし」（なし・弱め・ふつう・強め。設定の「見た目」、背景のシート、デザインのページで。保存はデザインの `frost`）。ぼかしはやわらかい絵に描きこむ（`SOFT_BLUR`。画面をライブでぼかさない）。ふつうでは、鯉はやわらかい色のかたまりがゆっくり動くくらいに。文字が先に読める。「なし」ではページもモザイク（重くなる）。タイマーでは背景をくっきりのまま少しだけ薄め（眺めるための画面なので）、「眺める」では何もかけない。歩く人は、ページでは網点をやめて影だけをなめらかに
- 設定の「見た目」: テーマ（横に並んだテーマを押すとその場で変わる。前はマイページにあった）・デザイン・背景・背景のぼかし・カードの背景
- カードの白さは「カードの背景」（うすい・ふつう・こい・白。背景のぼかしと同じ3か所で。保存はデザインの `cardFill`。タイマーのカードも少し薄めに同じだけ変わる）
- カードは白いガラス（`src/ui/Glass.tsx` の `Pane`）: ページでは背景のすりガラスがぼかしているので、カードは白い膜と上からの光だけ（ぼかしを何枚も重ねないので軽い）。タイマーのカードと経過時間は、自分でうしろをぼかす。縁の線と影はなく、カードの外へ自分の色がうっすらにじむので、境目が背景に溶ける。小さな選択肢のタイルは濃い膜
- 時間割の画面でだけ、鯉はカードをよけて泳ぐ（`backdropAvoid`）。タップでエサ（`feedAt`）

テーマは色だけでなく、ホーム・タイマー・下のバーの描き方まで持てます。ひとつのテーマを、別のアプリを作るつもりで作れるようにしてあります。

**いまは、どのテーマもスタンダードと同じレイアウト・大きさを使っています**（テーマで変わるのは色・字・角・質感と、出来事の演出だけ）。各テーマの独自の画面はコードに残してあり、`src/themes/index.ts` の `OWN_LAYOUT` を `true` にすると戻ります。

- **大本のレイアウト**は `src/screens/layout.ts` の1か所だけ。ホームのブロック（`HOME`）、タイマーの部品と3つの段（`TIMER`）、タブ（`TABS`）。
  ここを変えると全部のテーマに届きます。
- **中身と操作**は `src/screens/model.ts` で全テーマ共通（今日の時間、勉強中のセッション、次にやること、連続記録、グラフ、ToDo、締切、仲間、画面の移動）。
  テーマは見た目だけを決めます。
- **テーマのアプリ**は `src/themes/<id>/` に1フォルダ。ホーム（ページ・ヘッダー・ブロックの枠・各セクション・並べ方）、タイマー（ページ・部品・並べ方）、
  下のバー、出来事の演出を、描きたいものだけ持ちます。描かなかったものは標準の描き方がそのテーマの色と文字で出るので、途中までのテーマでも壊れません。
  並べ替えは `arrange()` を通るので、大本にブロックが増えても、テーマが知らないブロックが消えることはありません（`src/screens/__tests__/layout.test.ts`）。
- **色・文字・角・影・質感**は `src/design.ts` の `THEMES`。勉強のページ・記録・設定など、テーマのアプリが描かない画面はこれで着せ替わります。
- **押したときの反応**もテーマごと（`Reaction`）: 縮む・沈む・明滅・カクッ・版ずれ・選択枠など。どれも押すと素早く変わり、離すと行きすぎずに戻る（はねる・ぷるんとする反応はやめた）。動きと透明度だけなので、まわりはずれません。
- **動き**（`MOTION.md`・`src/ui/motion.ts`）: iOS と同じく、跳ねない・揺れない。ばねは行きすぎない設定（`dampingRatio: 1`）だけで、長さと曲線は7つ（押す・離す・小さな切り替え・移動・出す・閉じる・フェード）だけ。指で動かすものは指についてきて、離すと指の速さを引き継いで止まる（行きすぎない）。くり返す飾りの動き（点の明滅・ゆらゆら）と、ふくらんでから戻るポップはなし（ただ1つの例外として、連続記録の炎だけはゆっくり揺れる。`motion.ts` の `flicker`）。動かすのは位置・大きさ・透明度だけ（幅や高さは動かさない）。毎秒変わる時間は、それを出す小さな部品だけが描き直す。跳ねる書き方は lint（`eslint.config.js`）とテスト（`src/lib/__tests__/motion.test.ts`）で止まる
- **出来事の演出**（`src/moments.ts`）: 勉強を始めた・ToDoを終えた・目安に届いた・記録した（レベルアップ・休み券）を知らせます。
  テーマは `moments` でそれぞれの演出を出せます（何が起きたかは、いつも通知でも出ます）。
- **テーマを足すとき**（ほかの会社と組むテーマなど）: `src/themes/<id>/` を作り、`src/themes/index.ts` の `KITS` と `src/design.ts` の `THEMES` に1行ずつ足すだけ。
  実在のキャラクターやロゴは、権利を持つ会社との契約があるときだけ使います。

## 操作のポイント

- ブックマーク: タイムラインの投稿の しおりのボタンで保存（もう一度押すと外す）。保存した投稿は、ホームを右にすべらせたメニューの「ブックマーク」に新しい順で並ぶ（`src/app/bookmarks.tsx`）
- メニュー: ホームを右にすべらせると、ホームが指について右へずれ、下からメニューが出てくる（半分を超えるか、素早く払えば開く。基本のテーマでは左端のつまみはなし。VoiceOver では「メニューを開く」の操作で開く）。設定・科目と色・ブックマーク（保存した数）・テーマ（デザインのページへ。いまのテーマが右に出る）・背景（鯉の池・サメの海・歩く人・なし。いまの背景が右に出る）、いちばん下に「時間割に追加」。時間割にない勉強は、勉強バーの「勉強を開始」から。ホームを左にすべらせるか、押すと閉じる（`src/screens/SideMenu.tsx`）。メニューから開くページ（設定・科目と色・ブックマーク・テーマ）は、右からすべってこずにパッと出る（メニューは下で閉じる）。お知らせはホーム右上のベル、フォローはマイページから。デザインのページは `/design` に残っている
- テーマ（デザインのページの上）: 基本（スタンダード）は、背景・メインの色・角・タイマーの色を自分で選べる。それ以外のテーマは色・字・角・質感と出来事の演出が変わる（レイアウトと大きさはスタンダードと共通。独自の画面も作ってあるが、いまは使っていない。上の「テーマの仕組み」）。
  デジタル（LCD・ターミナル・サイバー。7セグの液晶の携帯機器）／8bit（レトロゲーム・ドットの夜・ピコピコ。RPGのステータス画面）／かわいい（ゆめかわ・ミルクティー・ソーダ。シール手帳ともちもちのキャラ）／油絵（ひまわり・星月夜・睡蓮。アトリエのキャンバス）／まるごと（ピクセル箱・ネオン・インク・方眼・ガリ版）。同じファミリーの3つは、同じアプリの色違い。
  同梱のフォント（DotGothic16・Bricolage Grotesque・Silkscreen・Rajdhani・Dela Gothic One・IBM Plex Mono）は、読み込むまでは普段のフォント

- 科目と色: 科目は細かく分けられる（英単語・数IA・古文・日本史 など。よくある分け方は押すだけで追加）。それぞれ教科（英語・数学・国語・理科・社会・情報・その他）に入る（名前から推し量る：数IA→数学、日本史→社会。変えられる）。色は固定で、教科ごとの色の濃淡（英語は紫、数学はオレンジ、国語は黄土、理科は青緑、社会は赤茶、情報は灰青）を、科目を作った順に1つずつもらい、あとから変わらない（`src/data.ts` の `AREA_SHADES`）。教科を移すと、移った先の色になる。色を選べるのは「その他」の科目だけで、どの教科とも重ならない色から。グラフの色もこの色で、グラフ独自の色の切り替えはない。凡例は色と一緒に科目の絵も出す。前の保存は、読みこむときに教科の色へ直す（化学の赤は理科の濃い青に）。記録がある科目を消すと「しまう」になり、グラフには残る

- 下のバーの真ん中は「勉強」のページ。一番上が時間割（曜日ごと。押すと編集）。
  時間割の「追加」は、カレンダーの予定の入力画面と同じ形のシート（締切の「追加」は同じ形の別のシートで、名前・日付・メモだけ。予定と締切は切り替えない）。上に ✕・「予定を追加」・✓（科目の色。締切は赤）。何をやるか、開始（日付と時刻）・終了（日付と時刻。0時をこえて翌日にできる。終わりを開始より前にすると自動で翌日）・繰り返し（しない／毎週）、科目（自分で書く。色を選ぶとグラフの色になる。いまの科目は下のボタンからも選べる。新しい名前なら科目が増える。ボタンの列の最後の「＋ 科目を足す」で、その場で名前と色を決めて科目を足せる）、メモ。日付や時刻を押すと、その行のすぐ下に iPhone のカレンダーや時刻のホイールが開き、下の行はなめらかに下がる。キーボードは欄を押すまで出ない。締切は名前・日付・メモ
  予定はその日だけ（前に作った毎週の予定はそのまま残る）。勉強タイマーのルール: 予定は始める時刻と終わる時刻（前に作った終わりのない予定は次の予定が始まるまで）。次の予定の時刻にお知らせが届く（勉強中でも届く）。ストップしなければ、次の予定の時刻を過ぎてもそのまま測り続ける。タイマーとバーには「次の数学（19:00）まで あと…」が出て、過ぎると赤で「+…」。記録はやった分だけ（先の7日分のお知らせをスマホの中で予約。設定でオフにできる。計算は `src/lib/reminders.ts` の `timetableReminders`、予定の区切りは `src/lib/timetable.ts` の `spanEnd`）。前に作った長さのある予定や時刻なしの予定もそのまま使える
  （「次は」と開始ボタンのカード、ToDo、タイマーの設定のカードはいったん外した。勉強中は真ん中を2回押すとタイマーが開く）
- 勉強バー: 下のバーのすぐ上に、音楽アプリのミニプレイヤーのようなバーがいつも出ていて、どのタブにも残る。勉強していないときは、右に「勉強を開始」。左には時間割：予定の時刻になったらその予定（やること・メモ）、それまでは次の予定と時刻。「勉強を開始」は、バーに出ている予定を始める（時刻の来た予定。まだ時刻前なら次の予定を、その長さのまま早めに）。今日の予定がもうなければ、何も聞かずに「自習」としてすぐ始まり、タイマーの画面に移る（`startFree`。科目はまだなく、今の時刻から今日の時間割に灰色の「自習」のカードで入る）。自習は、終わって記録するページで科目を選び、内容（例：相対性理論）を書く。どちらも選ばず・書かずに「記録する」だけでもよく、そのときは「自習」のまま記録され、勉強のページの時間割の線の上に、その時刻の灰色の点と「仕分ける」で並ぶ（その日のうちだけ。日付が変わると、仕分けていない自習は「自習」として片付く：`rollDay`）。押すと内容を書いて、科目を1回押すだけで仕分けられ、時間割の「自習」の行もその科目と内容に変わる（`sortFree`。グラフでは仕分けるまで灰色の「自習」）。いくつかの科目をまとめてやったときや、書くほどでもないときは「自習のまま」：記録のページの科目の先頭のタイル、または仕分けのシートの「自習のままにする」で、自習として残し、仕分けの一覧には出さない（`kept`）。内容はグラフの内訳に出て、時間割のカードも選んだ科目と内容に変わる。バーを下に引いて記録するときも、自習なら記録のページへ（`FREE`）。勉強中は、時間が進んでいる間はアイコンの左上に蛍光緑の点、一時停止中は文字が紅色（「一時停止中」とは書かない）。勉強した時間と一時停止、時間割から始めたときはその長さまでの細い線（中は緑、こえると赤）。押すとタイマーが下から開く。下に引っぱると時間が止まり「記録しますか？」のカードが出る（記録まちがあれば「ぜんぶ記録する」）。バーを消したまま時間が裏で進むことはない
- タイマー（標準のデザイン）: 今日の予定を1枚ずつのカードにして横に並べる（音楽アプリのアルバムのように、指で横にすべらせると1枚ずつ止まる。真ん中から離れたカードは少し小さく暗い。`src/screens/timer/cards.tsx`）。カードは音楽プレイヤーを大きくひらいた形（白いカードに細い縁）。上に予定の絵（写真を選んでいればその写真、なければ科目の色に科目の絵と名前）と、その上に小さく状態（勉強中・一時停止中・予定クリア · 延長中・記録まち、まだの予定は時刻）。その下に教科（大きく）とメモ（なければやること）、右に ♡。♡ を押すとその予定を「よく使う」に入れる（もう一度押すと外す。保存はストアの `favorites`）。その下に予定の長さへの線（過ぎた分はオレンジでつなげる）、線の下の左に勉強した時間（大きく。長押しでフォントを選ぶシート：縦長・縦長・細・細い・太い・丸い・明朝・明朝・太・等幅。設定はデザインの `timeFont`、一覧は `src/ui/timeFonts.ts`）、右にのこり（−20:43。過ぎたら +4:12 をオレンジで）。いちばん下にボタン（記号だけ。名前は VoiceOver 用）：左にペン（予定を編集）、まんなかに大きな黒い丸（▶ 始める・再開・続ける／❚❚ 一時停止）、右に ✓（終わって記録する。記録まちはその分を記録。まだの予定では「この予定を終わりにする」のメニュー）。勉強した時間は行の高さを決めずに描き（縦長のフォントでも上下が切れない）、長くなると幅に合わせて小さくなる。言葉は前向きに（オーバーとは言わない）。カードは画面の高さに合わせて縦に伸び（幅の1.8倍まで。絵がそのぶん大きくなる）、カードの下に余白が残らないようにする。いちばん下に広告のカード（いまは例。動きも音もなく、左上に必ず「広告」）。先頭は透明な「予定を追加」のカード。「…」で、この予定を終わりにする・予定を編集。次の予定へは、カードをすべらせて「始める」を押すだけ。いま勉強していた分は止まって「記録まち」になる（1分未満ならそのまま切り替わる。記録まちの予定をまた始めると続きから）。記録はひとつずつでも、最後に「まとめて記録」でぜんぶ一度にでもよい。記録するとその予定は今日は終わりになり、カードが消える（勉強のページでも「終わった」と出る）。記録したあとはタイマーの画面のまま。「並べ替え」で今日の予定の順番を入れ替えられる（≡ を押したまま上下に。記録まちと勉強中の予定は先頭で動かせない。順番はその日だけで、時刻は変わらない）。いちばん上のバーを持って（どこからでも）下に引っぱると、Apple Music のように指についてきて、うしろに開く前の画面が見える。離すと小さくなって勉強バーに戻る（`TimerFrame`）。背景は左上の「背景」か、横のメニューの「背景」で選ぶ：鯉の池（ふつう）・サメの海・歩く人・なし（科目の色に染まる）。どのページとも同じ鯉が、ここではカードをよけて泳ぐ（上の「背景」）。上には「今日の時間割」と日付（大きめで読みやすく）。右上の「眺める」で文字とボタンが消えて背景だけになり、時間と「戻る」が残る。前の時計の描き方（文字盤の切り替え）は `standard.tsx` に残っていて、テーマのタイマーが使う

- メッセージ（1対1のチャット）: ホーム右上の吹き出し（前のプロフィールの丸の場所。マイページは下のタブから）から。未読があると赤い点。一覧は新しい順で、相手・最後のメッセージ・時刻（今日は時刻、昨日、今週は曜日、その前は日付）・未読の数。右上のペンで新しいメッセージ（フォロー中の人が先、勉強部屋の人も）。人のメニュー（アイコンを押すと出る）の「メッセージを送る」からも開ける。トークは自分が右に黒、相手が左に白で、横に小さく時刻。日が変わると「今日・昨日・10月26日(月)」の区切り。文字とスタンプ（グループと同じスタンプ）が送れる。開くと既読になる。ブロック中の人には送れない（一覧からも消える）。保存はストアの `dms`（相手の名前ごと）。いまはこのスマホの中だけで、相手には届かない（届けるにはサーバーと、電気通信事業の届出が要る）。サンプルのアカウントには mio・そら・kaito とのやりとりが入っている

- 下のバーと勉強バーは浮いた Liquid Glass（iOS 26 はシステムのガラス。下のバーは regular に白を少し足して、うしろは透けるがよくぼける（clear では透けすぎた）。勉強バーは文字をひと目で読むので regular に白を足したすりガラス。それ以外の端末は強いぼかしに膜、左上からの光、明るい縁で、勉強バーの膜は濃いめ）。アイコンだけで、真ん中（時計）が「勉強」のページ。勉強中は時計に小さな緑の点がつく（一時停止中は黄色）
- マイページ: クレジットカードと同じ比率のカードの下に、データを4ページに分けたタブ（上に張り付く）。成長（グラフのカードは横にスワイプで「この7日間 → これまでの勉強時間」と1枚ずつ切り替わる（長く引いても1枚、カクッと止まる。2枚とも同じ高さ）。この7日間は棒を押すとその日の時間と科目ごとの内訳が出る（もう一度押すと戻る）。これまでの勉強時間は右上の小さな縦のスライダーで足（日・週・月）を変えられる。その下に次のバッジのカード、昨日・先週・先月との比較。バッジはホームのいちばん下）／記録（今日の記録と半年の草）／グラフ（日・週の棒グラフ、科目、偏差値）／投稿
- 勉強した中身: 予定から始めた勉強は、記録にその予定のメモ（なければやること）を「何を」として残す（`Session.what`。記録するときに書いたメモは別に `note`）。予定なしの勉強は、記録のメモが「何を」になる。グラフの棒を押すと、その日（または1時間）の内訳が出る：科目ごとに、何をどれだけ（例：物理 1時間30分 ─ 相対性理論 1時間・電磁気 30分。長い順、4件まで＋ほか）。マイページの「この7日間」は、棒を押して下の「内訳 ›」でシートが開く（`src/ui/Breakdown.tsx`、集計は `src/lib/history.ts` の `contentsOf`）。見本の記録にも中身が入っている
- 書いた内容の候補: 内容を書く欄（予定のやること・予定のメモ・記録のページの内容・あとで仕分けの内容）の下に、前に書いた内容が丸いボタンで出る。選んでいる科目のものが先、多く書いたものが先。打つと、その文字を含むものに絞られる。押すと入る。同じ内容が同じ書き方になり、グラフの内訳で1つにまとまる（`src/lib/contents.ts`・`src/ui/ContentHints.tsx`）
- フォロー・フォロワーは、マイページの数字を押すと一覧が開く
- タイムライン: 右下の＋で投稿。今日の記録をつけて投稿できる
- みんな › いま勉強中: 絞り込みの最後の＋で、志望校の絞り込みを足したり、人をさがしてフォローしたりできる
- 日付・時刻・長さはどこでも iPhone の選び方（日付はカレンダー、時刻は5分きざみのホイール、勉強した長さは時間と分のホイール、はじめの登録の生まれた年は年のホイール）。Android はその端末のダイアログ、ブラウザはブラウザの日付・時刻の欄（`src/ui/DateTime.tsx`）
- 0時をまたいだ勉強は、記録するときに0時で分けて、前の日と終わった日にそれぞれ入る（前の日の連続記録も切れない。`splitAtMidnight`）
- 今日の合計とバーは、1回ずつの記録から計算する。記録タブの「今日の記録」で押すと直せる／消せる、「手で追加」で今日・昨日の分を足せる
- 勉強のページには時間割と締切がある。今日の時間割は1日を1本の線にする（電車の路線図のように）。時刻は線のすぐ左に右寄せの等幅でそろえる。線は過ぎたところが実線、これからは点線で、いまの時刻に赤い点と細い横線（「19:20」）。過ぎたものは細い1行で時刻の順に並び、点の形で状態がわかる：終わった予定は科目の色の点（右に、予定の長さに対して何分やったかの小さな棒と分数。予定より長い分はオレンジ）、やらずに過ぎた予定は輪だけ（科目名に取り消し線）、まだ仕分けていない今日の自習は破線の輪（「仕分ける」）。その下に、いまの予定（科目の絵が線の上に乗り、灰色の地）と、これからの予定（小さな白い輪、絵は右端）。ほかの曜日は普通の行だけ。行は左から、時刻・予定のアイコン（写真か科目の絵）・科目名（下にメモ。メモがなければやること）。再生ボタンはなく、押すと編集。ここからは始めない：勉強の開始とタイマーは下の勉強バーからだけ（真ん中のタブをもう一度押してもタイマーは開かない）（「〜を始める」のカード、ToDo、タイマーの設定のカードはいったん外した。決め方を考え直し中）
- ToDo（いまは勉強のページから外している。ホームの「ToDoの残り」から見られる）: ＋追加、右の「…」（または長押し）で編集・上下に並べ替え・削除。締切にひも付けると締切の進み具合に数える
- 締切: ＋追加、押すと削除。残り日数は今日から計算
- ToDoから始めた勉強は、記録するとそのToDoが完了になる
- 人の名前やアイコン（勉強中・ランキング・投稿・チャット）を押すと、フォロー・ブロック・通報ができる。ブロックした人はどこにも出ない
- いま勉強中の友達（ホーム）: 証券アプリの保有一覧のように、最大4人。今日の時間と昨日との差、この7日間の小さな線。いつもは今日の時間が長い順。並び順のボタンで「名前順」「自分で並べる」も選べる。右端の ≡ をつかむ（または行を長押し）して上下にずらすと、行が浮いて指についてきて、ほかの行はバネでよける（自分の順として保存）。行を左にスワイプするとその人を非表示（元に戻すも出る）。右上の「もっと見る」で全員を縦に並べたカードが画面の真ん中に開き（後ろはぼける）、非表示にした人もそこから戻せる。行を押すとその人のメニュー
- 勉強中は勉強バーがタイマーになり、ほかのタブにいるときは真ん中の時計に蛍光緑の点がつく（一時停止中は紅色）
- ホームの今日のバー（科目ごとの色分け）は、押したままなぞるとその科目の時間が出る
- ピーチ色の「日連続」のカプセルを押すと炎がはねる（色はデザインでメインの色・ホワイトにも変えられる）
- 画面の上の切り替え（タイムラインのおすすめ／フォロー中、みんなのいま勉強中…、マイページの成長…）は中央にそろえている
- 休み券: 7日続けて勉強するごとに1枚もらえる（最大3枚）。勉強しなかった日があると自動で使われ、連続日数が途切れない
- 経験値（EXP）とレベル: 勉強1分で1 EXP、1日の目標を達成した日は+30 EXP、ToDoを1つ完了で+10 EXP（1日5つまで）。記録から毎回計算する（`src/lib/exp.ts`）。ホームの左上の「Lv.」を押すと、次のレベルまでと今日のEXPが出る。マイページのカードにもレベル。記録するとEXPが出て、レベルが上がると「レベルアップ！」
- グループのチャットでは、入力欄の左のハートでスタンプを選べる
- タイマーの「終わる」で時間が止まり、投稿を書くような記録の画面へ。左上「続ける」でタイマーに戻る（時間がまた進む）、右上の青い「記録する」で保存。メモ（どこまでやった？どうだった？140字まで、なくてもOK）、時間（−/＋で5分ずつ直す）、時刻、予定の中かこえたか、「自分だけのメモ／タイムラインにも投稿する」の切り替え。下に今日の合計がどう変わるかと文字数の輪
- 記録の棒グラフ（bencho の stacked bars）: なぞると1本が囲まれてほかが薄くなり、内訳が横に出る。日／週で伸び直す。赤は目標に足りなかった分
- 偏差値のカード: 線をなぞるとその週の日付と値が小さなタグで出る。3か月／半年／1年で切り替え
- タイマー: 目盛りは「時間」と「分」の2本で、合計は最大5:00。ドラッグ・はじいて残り時間を決める（分は5分ごとに止まる）。動きはすべてUIスレッドで、指に遅れずに動く
- 数字（bencho の rolling counter）: 桁ごとに回って少し行き過ぎて止まる。定員の ＋／− は長押しで加速、数字を上下にドラッグしてもはじける
- 草は指で押したままなぞると、その日の時間が出る
- グラフは出てくるときに動く（棒は下から伸び、線は左から描かれ、草はマスがカードのようにひっくり返って灰色から緑になる（左上から波のように）、数字は回る）。アプリを開いたときと、タブを切り替えてそのページに戻ったとき（`src/ui/appear.ts`）
- 今日の勉強のテープ: 長く勉強した日は目盛りが自動でまばらになる（1時間ごと → 2時間ごと…）。目標のラベルと重なる数字は出さない
- お知らせは右スワイプで既読、左スワイプで削除（元に戻せる）
- 上から出る通知は、重なっているところを押すと広がる。上にシュッとスワイプすると消える
- 大学検索で2校以上チェックすると、比較のトレイが出る

## Expo Go で動かない機能について

ロック画面や iPhone の Dynamic Island に勉強時間を出す機能（Live Activities）は、Expo Go では作れません。
開発ビルド（`eas build --profile development`）が必要なので、このモックではタブの真ん中のボタンと、勉強バーで代わりにしています。

# 「ぽむの おやすみ かぞえうた」 YouTube 公開パッケージ

レポート「子ども向けYouTube視聴トレンド分析」の推奨に沿って設計した第1本目です。
狙ったジャンル: **未就学児向け・キャラクター主導・低刺激／就寝向けアニメ**（成長率トップのニッチ、保護者が「選んで見せる」設計）。

| 項目 | 内容 |
| --- | --- |
| 対象年齢 | 1〜4歳（保護者との共視聴前提） |
| 尺 | 2分45秒（ショートではなく長尺。テレビ画面での共視聴を想定した横型16:9） |
| 学び | 数字 1〜5、色 4つ（あか・きいろ・むらさき・みどり） |
| 演出方針 | カット数を最小に、動きはゆっくり、色はパステル、効果音は柔らかい鐘のみ |
| 未対応 | ナレーション音声（この環境では音声合成ができないため、下の台本で収録 or TTS してください） |

## ファイル

- `pomu_oyasumi_kazoeuta.mp4` 本編（1920×1080, 24fps, BGM・効果音入り、ナレーションなし）

## 続編の作り方（スクリプトの変更点）

| やりたいこと | 変更箇所 |
| --- | --- |
| 数字を 6〜10 に | `NUMBERS` のリストと `T_COUNT` の長さ（1つ12秒） |
| 色や物を変える | `COLORS` と `make_item()` の描画 |
| 尺を伸ばす | 各 `T_*` の秒数。合計は `TOTAL` に自動反映 |
| キャラの表情を増やす | `make_pomu()` の `mouth` 引数 |

レポートで指摘した通り、このジャンルは再生は伸びるが広告RPMは最低水準です。3本目までに「シリーズ化」「グッズ・教材タイアップ」「多言語版（英語音声）」の設計を入れることを勧めます。

# 複利のしくみ（80秒 / 1920x1080 / 30fps）

お金の仕組み解説シリーズの1本目。100万円を年5%で30年置いたときの単利（250万円）と複利（432万円）の差から入り、単利と複利、30年グラフ、72の法則、毎月積立（3万円×30年）、3つのコツの順に見せる。

- `index.html` … 映像と音のすべて。`window.renderAt(t)` は t だけで1フレームを描く純粋関数。`?t=12.5` でその瞬間に固定、パラメータなしならブラウザで再生。
- `render.mjs` … ヘッドレスChromeで全フレームを書き出し、Web Audioで合成した音を -14 LUFS / -2 dBTP に正規化して MP4 にまとめる。
- `compound-interest.mp4` … 完成品。

```bash
node render.mjs                  # out/compound-interest.mp4
node render.mjs --stills 5,35    # 確認用の静止画
```

数値はすべて `index.html` 冒頭で計算している（年利 `R`、元本 `P`、積立額 `MONTHLY`、年数 `YEARS` を変えれば図も音のタイミングもそのまま追従）。
年5%は計算上の仮定で、税金・手数料は考慮していない。

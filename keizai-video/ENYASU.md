## 事実確認で直したところ

1回目の判定は「不合格」でした。主な直しは次のとおりです。

| 何が問題だったか | どう直したか |
| --- | --- |
| 「利上げがある確率が9割近く」と言っていたが、89%は「上げ幅が0.25ポイントになる確率」だった（残りは0.5ポイント） | 台本と図を「利上げの幅の見方」に直し、残りの点を別の色で示した |
| 「およそ2か月半ぶり」は報道によって「2か月ぶり」とも書かれていた | 全社で一致する「9月の初め以来」にした |
| 財務大臣の発言の後半は、放送局によって助詞が1つ違った | かぎかっこに入れるのは、全社で一字一句同じ前半だけにした |
| 「介入から3か月半で160円に戻った」は、4週間後にいったん160円台に戻った経過を落としていた | 途中経過（8月28日 160円台、9月8日 152円台）を台本と年表に入れた |
| 為替介入の説明が「円買い」だけだった | 「通貨を売り買いして相場を動かそうとすること」に直した |
| 介入の効き目の例が、短かった例だけだった | 1年以上かかった例もあると足した |
| 写真に、外国の両替所、別の省庁の看板、古い紙幣、個人名の入ったレシートなどがあった | 16枚を差し替え、または切り取った |

## 公開前に人が確かめること

事実確認の報告の「人の目で確かめること」から、主なものです。

1. 財務大臣の発言（11月13日午前）を、TBS NEWS DIG か ANN の映像で1回聞く。
2. 公開日の円相場と、政府・日銀の動き。160円台に定着したり、介入があったりすれば、掴みと3か所目を書き直す。
3. 12月の利上げの見方（アメリカ・日本）が変わっていないか。
4. アメリカの消費者物価指数の発表文を、米労働省のページで開いて見る（確認役は直接開けなかった）。

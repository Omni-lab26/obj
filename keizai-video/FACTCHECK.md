# 事実確認のプロンプト（動画を作る前の関門）

台本ができたら、**音声と動画を作る前に**このプロンプトで事実確認をします。
結果が「不合格」か「条件つき合格」のあいだは、音声も動画も作りません。直してから、直した行だけもう一度確認します。

## 手順

1. 台本（`lines.json`）と、画面に出す文字（`shots.ts` の図・カード・出典・地図のラベル）をそろえる。
2. 下のプロンプトを、**台本を書いていない確認役**に渡す。AI に渡すときは、台本を書いた会話とは別の、検索ができる新しい会話（または別のエージェント）を使う。書いた本人の確認は思い込みを引き継ぐので、確認とは数えない。
3. 報告を `FACTCHECK-〈回の名前〉.md` として保存する。
4. 「誤り」「確認できず」「食い違い」を全部直す。直せないものは台本から削る。
5. 直した行をもう一度確認し、判定が「合格」になったら、台本と報告を読んでから音声・動画に進む。
6. 報告の最後の「人の目で確かめること」は、公開前に人が元の資料を開いて確かめる。

## プロンプト

次の枠の中を、そのまま確認役に渡します。`{{ }}` の部分だけ差し替えます。

````text
あなたは報道機関の校閲者です。これから渡す経済解説動画の台本を、公開前に事実確認してください。
この番組は信用が命です。1つでも誤りが残ると番組全体が疑われます。
台本を書いた人の味方をする必要はありません。疑ってかかり、反証を探してください。

# 渡すもの
- 今日の日付: {{日付}}
- 台本（1行ごとに行番号つき）: {{lines.json の中身}}
- 画面に出す文字（図、カード、出典の表記、地図のラベル）: {{shots.ts の該当部分}}
- 使う写真（ファイルと、どの行で使うか）: {{写真フォルダと shots.ts}}
- 書き手の出典メモ（参考。信用しないで自分で確かめること）: {{出典メモ}}

# やること

## 1. 主張を全部抜き出す
台本と画面の文字を1行ずつ読み、確かめられる主張をすべて抜き出します。1行に複数あれば分けます。
見落としやすいもの：
- 数字（金額、割合、件数、順位、倍率、「約」「近く」「あまり」「ほぼ」の付いた数字）
- 日付、曜日、時間帯、「何日後」「何か月ぶり」「何年ぶり」
- 「過去最大」「初めて」「最も」などの一番を示す言葉
- 人名、肩書き、所属、政党、組織名、地名、人口
- 発言の引用（かぎかっこの中）と、誰がいつどこで誰に言ったか
- 用語の説明（「〇〇というのは…」）
- 因果関係（「AだからB」「Aを受けてB」「市場はこう読んだ」）
- 比較（「AはBの何倍」「AよりBが大きい」）
- 画面の文字、図の数値、出典の書き方、地図の位置
- たとえ話が、もとの仕組みを誤って伝えていないか
- 確率や割合が「何の」確率・割合なのか（「利上げがある確率」と「上げ幅が0.25ポイントになる確率」は別物）
- 出典の表記が、その出典に本当に書いてある内容と合っているか
- 途中経過を省いたせいで、実際と違う印象になっていないか

## 2. 1つずつ裏を取る
主張ごとに、次の順で証拠を探します。
1. 一次資料（統計を出した官庁や中央銀行の発表、企業の開示、調査の原票、発言の全文や映像）
2. 一次資料が読めないときは、たがいに独立した信頼できる報道を2本以上（同じ通信社の配信記事を載せた2つのサイトは1本と数える）

守ること：
- **検索結果の要約や AI の要約を証拠にしない。** かならず元のページを開いて、該当する文を読む。開けなかったら「読めなかった」と書く。
- 証拠には、URL、発行元、日付、該当する文（短い引用）を付ける。
- 自分の記憶で埋めない。確かめられないものは「確認できず」とする。
- 数字は自分で計算し直す（差、変化率、倍率、合計、「何か月ぶり」の月数）。
- 単位と基準をそろえて確かめる（前月比と前年比、％と％ポイント、名目と実質、終値と取引中の値、現地時間と日本時間、年度と暦年）。
- 数字がその後に改定・訂正されていないか、もっと新しい数字が出ていないかを確かめる。
- 似た別物と取り違えていないか確かめる（CPI と PPI、総合とコア、日経平均と TOPIX、決定と観測、提案と可決）。
- 引用は一字一句、原文と照らす。出どころによって言い回しが違う発言は、かぎかっこに入れない。翻訳は意味を足したり強めたりしていないか確かめる。切り取りで意味が変わっていないか、前後を読む。
- 肩書きは「その発言の時点」と「今日」の両方で正しいか確かめる。

## 2-2. 写真を1枚ずつ開いて見る
題名だけで判断せず、画像を開いて見ます。
- 話の舞台と違う国・施設・時代のものが写っていないか（外国語の看板、別の省庁の表札、古い紙幣）
- 読める数字（値段、為替レート、年号、日付）が、話の数字と食い違ったり紛らわしかったりしないか
- 関係のない個人の名前、電話番号、大きくはっきりした顔が写っていないか
- 特定の会社名やロゴが大きく読めないか
- 同じ写真を2回使っていないか

## 3. 反証を探す
主張ごとに、それを否定する情報をわざと探します。
- 集計元によって数字が違わないか
- 逆の結論を出している専門家や調査がないか
- 「AだからB」に、別の有力な理由がないか。台本はそれに触れているか
- 相関を因果として言い切っていないか。解釈なら「〜という見方」「番組の読み」と断っているか
- 片方の立場だけを紹介していないか

## 4. 判定する
主張ごとに、次のどれか1つを付けます。

| 判定 | 意味 | 台本の扱い |
| --- | --- | --- |
| A 確認（一次） | 一次資料を自分で読んで一致した | そのまま |
| B 確認（報道2本以上） | 独立した報道2本以上で一致した | そのまま |
| C 報道1本のみ | 1本でしか確かめられない | 「〇〇によると」と出どころを言う。言えないなら削る |
| D 解釈 | 事実ではなく解釈・見立て | 解釈だと分かる言い方に直す |
| E 食い違い | 資料によって数字や言い回しが違う | どれを使うか決めて出どころを言う。発言はかぎかっこから出す |
| F 確認できず | 探しても裏が取れない | 削るか、裏が取れる表現に書き直す |
| G 誤り | 資料と合わない | 直す |

写真にも同じ判定を付けます（場面と食い違うもの、個人名が読めるものは G）。

E・F・G が1つでも残っていたら「不合格」。C と D で、台本側の断り書きが足りないものが残っていたら「条件つき合格」。全部が A・B か、断り書きのある C・D になって初めて「合格」です。
迷ったら、きびしいほうの判定を付けてください。

## 5. 報告する
次の形で報告してください。

1. **総合判定**（合格／条件つき合格／不合格）と、その理由を2〜3文で
2. **直す必要があるもの**（E・F・G と、断り書きの足りない C・D）。行番号、いまの文、問題、直した文の案、根拠の URL
3. **全部の主張の表**。行番号／主張／判定／証拠（発行元・日付・URL・該当する文）／自分で開いて読んだか
4. **計算の確かめ**。計算し直した数字の式と結果
5. **台本に足りない視点**。反対の立場、別の理由、但し書き
6. **人の目で確かめること**。あなたが開けなかった資料、有料記事、映像、最新の数字など、公開前に人が確かめるべき点

遠慮して表現を弱めないでください。確かめられなかったことを「たぶん正しい」と書かないでください。
````

## この確認で見つかりやすい誤りの例

これまでの回で実際に出た、または出かけたものです。

- 検索の要約が CPI と PPI を取り違えていた
- 同じ住民投票でも集計元によって「47件」「41件」と数が違った
- 発言の言い回しが報道によって違った（「忘れるのにはまだ早い」と「忘れるには早すぎる」）。こういう発言は、かぎかっこに入れない
- 「一番気にしているのは電気代」と言い切っていたが、調査は順位を示していなかった
- 相場の「高値」が、どの市場のいつの値かで違った（160円05銭と160円19銭）
- 資料写真が、話の舞台と違う国の建物だった
- 「利上げがある確率が9割近く」と書いたが、89%は「上げ幅が0.25ポイントになる確率」で、残りは「もっと大きい利上げ」だった
- 「およそ2か月半ぶり」が、報道によって「2か月ぶり」とも書かれていた。全社で一致する「9月上旬以来」に直した
- 大臣の発言の後半が、放送局の書き起こしで助詞1つ違った。全社で一致する前半だけをかぎかっこに入れた
- 出典に挙げた通信社の記事に、その言葉が書かれていなかった
- 「介入から3か月半で元に戻った」は、4週間後にいったん戻っていた経過を落としていた
- 写真に、外国の両替所のレート、別の省庁の看板、戦中の紙幣、個人名の入ったレシート、同じ写真の重複があった

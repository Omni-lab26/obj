# Inchly ピボット：核に寄せる

見た目（UI）はそのまま。中身を「核の4つ」に寄せて、作り直す。

## 核

| 核 | 一言 | 画面 |
| --- | --- | --- |
| 測る | 始めるのが一瞬、止めたら記録が残る | タイマー、記録シート、手で追加、記録の手直し |
| 見える | 昨日より進んだがすぐ分かる | 今日のバー、草、連続日数、日／週グラフ、科目 |
| 一緒に | 仲間がいるから続く | いま勉強中、一緒に始める、グループ、もくもく会 |
| 次 | 次にやることが決まっている | ToDo（追加・編集・並べ替え・持ち越し）、締切とのひも付け、「次はいつやる？」 |

## 作ったもの

- **記録がデータになった**：1回ずつの記録（科目・分・メモ）を持ち、今日の合計と今日のバーはそこから計算する。
  タイマーで記録、手で追加（今日／昨日）、あとから手直し・削除できる。
- **ToDo**：追加・編集・上下の並べ替え・削除。締切にひも付けると、締切の進み具合が実際のToDoから出る。
  記録するとき「どのToDoを進めた？」で選んだものは完了になる。
- **締切**：追加・削除。残り日数は今日から計算。
- **端末に保存**：すべての状態をこの端末に保存し、アプリを閉じても消えない（計測中のタイマーも続く）。
  圏外でも使える。サーバーとの同期は設定画面に状態として表示（モック）。
- **アカウント**：はじめての起動で、サインイン → ニックネーム・学年・生まれた年 → 志望校と1日の目標 → 通知、の順に設定。
  13歳未満は使えない。18歳未満は「勉強中はフォロワーだけに見える」「メッセージはフォロー中の人からだけ」で始まる。
- **安全**：人の名前を押すと、フォロー・ブロック・通報ができる。ブロックした人は勉強中・投稿・チャットから消える。
- **設定画面**：公開範囲、メッセージを受け取る相手、通知の種類、ブロック中の人、同期の状態、データの書き出し、アカウントとデータの削除。

## 削ったもの

- 偏差値カードの「引っぱって更新」
- 投稿の画像
- ホームの「ひとやすみ」の読み物
- チャットのクイズ
- 塾の検索と広告枠

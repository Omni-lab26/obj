# Inchly の「Apple感」— 言語化と実装ルール

「Appleっぽい」を雰囲気の言葉で終わらせず、画面で確かめられるルールに落とす。
このファイルがそのまま実装の仕様。

## 0. 一言で

**主役はいつも中身。操作は中身の上に浮かぶガラスで、存在を主張しない。**
色も形も飾りも少なく、そのかわり一つひとつが正確に揃っている。

## 1. 6つの原則と、Inchly での決めごと

### ① 中身が主役、操作は浮かぶ（Deference / Liquid Glass）
- 画面は2層だけ。**下が中身**（白い地と白いグループ）、**上が操作**（タブバー、戻る・設定ボタン、セグメント、シート、通知、入力欄、タイマーの操作）。
- **ガラスは操作の層にだけ使う。** 中身のカードにはガラスを使わない（Apple のガイドラインどおり）。
- 中身はガラスの下を通り抜けてスクロールする。だからタブバーとヘッダーは画面に重ねて浮かせる。
- iOS 26 では本物の Liquid Glass（`expo-glass-effect` の `GlassView`、押すと反応する `isInteractive`）。
  それ以外（古い iOS・Android・Web）は、ぼかし＋半透明の白＋上辺のハイライトで同じ見た目を作る（`src/ui/Glass.tsx`）。

### ② 文字で階層をつくる（Typography）
- SF Pro（20pt 以上は Display、未満は Text）＋ヒラギノ角ゴ。
- iOS のテキストスタイルにそのまま合わせる：
  | 役割 | サイズ / 太さ |
  | --- | --- |
  | Large Title（タブの見出し） | 34 / Bold |
  | Title 2 | 22 / Bold |
  | Headline（行の見出し） | 17 / Semibold |
  | Body | 17 / Regular |
  | Subheadline | 15 / Regular |
  | Footnote | 13 / Regular |
  | Caption | 12 / Regular |
- 階層は**太さと色の濃さ**（label / secondaryLabel / tertiaryLabel）で作る。点・枠・バッジでは作らない。
- 大きい数字は **時計アプリと同じ細い数字**（SF Pro の Light / Thin、等幅）。太い数字を並べない。

### ③ 色は「系統色」と「アプリの色ひとつ」（Color）
- 地と文字は iOS のシステム色そのもの：地 `#F2F2F7`、グループ `#FFFFFF`、文字 `#000`、区切り線 `rgba(60,60,67,.29)` の髪の毛線。
  薄い文字だけは読みやすさを優先して、iOS の値より少し濃くする（二番目 `#6C6C70`、三番目 `#8A8A8E`。白地で 3:1 以上）。
- **アプリの色（tint）はひとつだけ**：Inchly の緑 `#2AA05A`（草の色）。押せるものはすべてこの色。ほかの色を「押せる」に使わない。
- 科目の色は iOS のシステム色（`#5856D6` `#FF9500` `#30B0C7` `#FF2D55` `#FFCC00`）で、**グラフの中だけ**。
- 赤は「足りない・消す」、オレンジは「締切が近い」だけ。
- Tailwind の既定色は使わない。

### ④ 形は同心円（Shape / Concentricity）
- iOS 26 の角は大きく、**内側の角＝外側の角−余白**で揃える（同心）。
  画面の端 → グループ 26 → 中の要素 14、ボタンはカプセル（高さの半分）。
- 一覧は「設定」アプリと同じ **inset grouped**：白いグループ、行の高さ 44pt 以上、区切り線は文字の左端から。
- 影はほぼ使わない。浮くのはガラスだけ。

### ⑤ アイコンは SF Symbols（Iconography）
- iPhone では `expo-symbols` で本物の SF Symbols を使う（Android / Web は同じ形の線アイコン）。
- 選ばれたタブは塗り（`.fill`）、それ以外は線。

### ⑥ 動きは物理（Motion）
- 押すと少し縮み、ばねで戻る。ガラスのボタンは押すと光る（iOS 26 の interactive glass）。
- 大きい見出しはスクロールすると消え、ガラスのヘッダーに小さい見出しが出る。
- 触覚（haptics）は「選んだ」「終わった」の2種類だけ。

## 2. 前回の「AI感」への答え

| 問題 | 今回の答え |
| --- | --- |
| Tailwind の既定色 | iOS のシステム色＋独自の緑ひとつ |
| 参考の寄せ集め | シグネチャを「尺取り虫（インチワーム）と定規」ひとつに決める。ほかは捨てる |
| 点・「·」・増減・凡例の多さ | 点は「いま勉強中」だけ。増減はホームの一か所だけ。凡例はグラフの下に一回だけ |
| すべてが同じ扱い | ホームの今日の数字だけ、カードに入れず細く大きく置く（意図的な例外） |
| 説明しすぎ | 使い方の注釈を消す。わかる形にする |
| データが整いすぎ | 休んだ日、昨日からの持ち越し、空の画面、雑な投稿を入れる |
| スタンプに作者がいない | キャラクターを1体（尺取り虫の「インチ」）。全部のスタンプがこの子の表情とポーズ |
| ホームに全部のせ | ホームは3つだけ：今日 / 今日やること / 今週。仲間と読み物は「みんな」へ |
| 意味のない仕掛け | 偏差値の「引っぱって更新」と、炎がはねるだけのボタンをやめる |

## 3. シグネチャ：尺取り虫と定規

Inch-ly＝「少しずつ」。尺取り虫は体を曲げて**一インチずつ**進む虫で、昔は物差しの代わりに長さを測った。
- 定規の目盛り：今日のバー、タイマー、今週の7日、イベントの時刻。
- 尺取り虫「インチ」：スタンプ全種、記録したときのスタンプ、空の画面。
- この2つ以外の装飾は足さない。

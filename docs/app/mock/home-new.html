ホーム（はじめての人）

登録した直後のホーム。記録がまだないので、草・連続・今日・バッジが「まだ」の形になります。名前は見本と同じ「はる」にしました。

  • まず「ようこそ」のトースト。それが消えてから、使い方の案内（アプリと同じ文）。暗い所か「次へ」で進みます。
  • 草は空きマスと今日の枠だけ。炎のボッは灰色で眠っていて、揺れません。
  • 今日は 0時間00分。締切の札はなく、テープは「目標まで 3:00」だけ。
  • バッジは 0 / 11。今のアプリは「1日5時間」「朝勉10回」が最初から達成になる不具合があるので、ここでは正しく「まだ」にしました。
  • 時間割がないので、バーは「今日の時間割 / このあとの予定はありません」。勉強を開始は自習で始まります。

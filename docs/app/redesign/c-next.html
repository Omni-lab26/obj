次の1枚

  1. 主役は「次にやる1枚」だけ。科目の字を紙の幅いっぱいに組み、押す所は「勉強を開始」の1つ。
  2. 画面の色＝その予定の科目の色。予定は色の紙1枚。朝は国語の黄土、夕方は英語の紫、夜は数学のオレンジ。
  3. 今日の合計と連続は、下の静かな1行。草・友達・バッジ・今日の内訳は、その行を上へ引く（押す）と出る1枚にしまった。
  4. タイマーは時間だけ。分と秒を2段で幅いっぱいに。進みは棒をやめて、紙の色が下から満ちていく。
  5. 部品は字で作り直した。タブは言葉、ボタンは長い板に丸いつまみ、そのあとの予定は下からのぞく紙のふち。

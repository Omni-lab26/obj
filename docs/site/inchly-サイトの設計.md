# Inchly 紹介サイト：piixpal に大胆に寄せた設計

参考：`REFERENCE.md`（piixpal のすべてを言語化した文書。値はそこから取る）。この文書は、それを Inchly にどう当てはめるかと、3人で同時に作るための約束を決める。

オーナーの言葉：「このサイト参考にして結構寄せて作ってくれ。大胆に寄せて。」
同時に守ること：piixpal のキャラクター、ロゴ、文章はまねない（REFERENCE 12.2）。型・色・線・影・動き方・構成は寄せる。

## 0. 一言で

「紙とインクと少しのライム」の上に、**Inchly の小さな住人（文房具と勉強の道具）** が住んでいる、iPhone の勉強アプリの紹介サイト。見出しの上をえんぴつが歩き、ボタンに折り鶴がとまり、ナビから目ざまし時計がぶら下がり、最後は **草の野原（緑のフッター）** で連続記録の炎が跳ねる。

寄せるもの（全部）：
- 地：白（既定）／紙／暗い の3テーマ、点の地、楕円のマスク、きらめき
- 線：2px のインク、ぼかしゼロの塊の影（下 4px、特別な1枚は右下 8px の色の影）、床の動かないボタン
- 文字：重く詰めた見出し、読みやすい本文、ピクセル書体のラベル（数・番号・指示）
- 部品：ヘッダー（すりガラス、スクロールで線）、テーマ切り替え、リボン、ピクセルの大ロゴ、ライムのマーカー、黒い窓、帯、カードの格子（住みか＋名前＋No.＋説明＋タグ＋黒い錠剤）、大舞台、棚、群衆の舞台、遊びのカード、手順、サンドボックス、表と黒いパネル、タグつきカード、破線の数字の箱、フッターのふちの模様
- 構成の型：小見出し（四角＋「話題 · 補足」）→ 2行の大見出し（句点）＋右に下そろえのリード → 触れる大きな物 → 中央のボタン列
- 動き：ピクセルは段、体はばね。触る前から反応。画面の外で眠る。動きを減らす設定で止まる

Inchly のものにするもの：
- 住人7種（下の 6章）。名前・絵・性格・反応はすべて自作
- ロゴ：上がっていく5本の目盛りのピクセルアイコン（アプリと同じ5色）＋「inchly」
- 大ロゴ：「inchly」をピクセル化。押し出しはライム
- 締めの色：フッターは **草の緑**（紫ではない）。ふちは段々の屋根ではなく **ピクセルの草の葉**
- 読書の進捗バー → **定規**（インチの目盛りつき。上をえんぴつが走る）
- リボンは事実だけ：「iPhone の勉強アプリ · 近日公開」（後ろ盾の表示はしない）
- 文章：すべて自分の日本語。型（短い2行と句点、道具を主語に、タグ3つの最後に小さな冗談、遊びへの一押しで締める）だけ学ぶ

## 1. ファイルと分担（3人が同時に作る）

```
site/
  index.html        … A
  css/site.css      … A
  js/pix.js         … B（住人のエンジンと絵、群衆、科目の顔、棚、大舞台）
  js/site.js        … C（テーマ、ナビ、現れる演出、大ロゴ、呼び出し、遊びのカード、サンドボックス、見た目の切り替え、定規）
  img/              … 既にある（画面写真と部品の切り抜き）
  favicon.svg       … C
```

- `index.html` は `<script src="js/pix.js" defer></script>` → `<script src="js/site.js" defer></script>` の順で読む。外部のスクリプトは使わない（フォントは Google Fonts だけ）。
- テーマのちらつき防止スクリプト（REFERENCE 6.3 の形。保存のキーは `inchly-theme`）は A が `<head>` の最初に書く。
- 約束（下の 9章）にない id・クラス・属性を JS が当てにしてはいけない。足りないときは各自の文書メモに書き、最後にまとめて直す。

## 2. 色（CSS 変数。A が `:root` と `html[data-theme=…]` に書く）

REFERENCE 2章の値をそのまま使う（`--paper --paper-2 --paper-3 --card --ink --ink-2 --muted --line --line-2 --code --lime --lime-2 --coral --violet --sky --sun --mint`、white／paper／dark の上書き、混ぜ色、選択、フォーカス）。

Inchly の追加：
- `--grass:#127A43`（フッターの地。白い文字が 5.4:1）
- `--grass-2:#1FA35B`（アプリの草の色。フッターの葉の影）
- `--brand-1..5:#E5484D #F2C46D #9AB8DB #5B8DEF #9D7BF5`（ロゴの5本の目盛りだけ）
- 科目の色（住みかや棚で使う）：英語 `#5856D6`、数学 `#FF9500`、国語 `#D9A300`、物理 `#3B82F6`、化学 `#10B981`、生物 `#22C55E`、地学 `#A16207`、世界史 `#C2410C`、日本史 `#DC2626`、地理 `#0EA5E9`、公民 `#6366F1`、情報 `#64748B`

REFERENCE 12.3 の弱点は直す：
- 明るい色の塗り（ライム・サン・スカイ・ミントなど）の上の文字は、どのテーマでも `#17121f` に固定。
- dark でも黒い錠剤と窓が消えないよう、`--code` の面に `box-shadow:inset 0 0 0 1.5px rgba(255,255,255,.12)` を足す。
- `theme-color` はテーマごとに変える。
- 小さな文字の色は 4.5:1 以上（コメント色は `#8d84a0`、フッターのリンクは不透明度 .95）。

## 3. 文字

```
https://fonts.googleapis.com/css2?family=Bricolage+Grotesque:opsz,wght@12..96,400..800&family=JetBrains+Mono:wght@400;600&family=M+PLUS+1:wght@400..900&family=DotGothic16&family=Silkscreen&display=swap
```

- `--f-sans:"Bricolage Grotesque","M PLUS 1",system-ui,-apple-system,"Hiragino Sans",sans-serif`（英数字は Bricolage、日本語は M PLUS 1）
- `--f-pix:"Silkscreen","DotGothic16",var(--f-mono)`（英数字は Silkscreen の大文字、日本語は DotGothic16）
- `--f-mono:"JetBrains Mono","M PLUS 1",ui-monospace,monospace`
- 見出しは REFERENCE 4.2 の大きさと太さ（720〜800）。和文があるので **字間は −0.02em、行送りは h1 1.12・h2 1.08**（REFERENCE 12.4）。英字だけの見出し（大ロゴ以外にはない）は −0.04em。
- 本文 `400 17px/1.7`（和文なので行送りを広げる）、リード 18px/1.7、カード本文 15.5px/1.65。
- ピクセルのラベル（小見出し、番号、ヒント、帯、タグの札）は `--f-pix`。日本語のラベルは DotGothic16 で、字間 .04em。英字は大文字。
- 強調（ライムのマーカー）はページで一か所だけ：ヒーローの「つみ上がる」。

## 4. 形と動き

REFERENCE 5章・8章の値をそのまま使う（線 2px、角 22/18/14/12/10/9/8/7/6/4/0、影、`--ease`、`--spring`、ボタンの床、現れる演出、テーマ切り替えの手順、コピーの反応の型）。
加えて：
- ホバーの効果は `@media (hover:hover)` の中にだけ書く。
- 押せる物は 44px 以上（テーマのボタン 40×40、呼び出しボタン 高さ 44、棚はマス全体を押せる）。
- 横スクロールの帯（スマホのナビ）には右端のフェード。
- スキップリンク「本文へ」。
- 動きを減らす設定：住人は静かな姿勢で止まる、大ロゴの雨・持ち上がりなし、帯・リボン・きらめき・ロゴの点・定規の走り手も止める。

## 5. ページの構成と文章（この順。id は約束）

すべての見出しは2行で句点。強調は1か所。感嘆符は使わない。

### header `#nav`
- 左：ロゴ（`a.logo` → `#top`）＝ 30×30 のピクセルアイコン（下の 7章）＋「inchly」（800 24px、字間 −.04em）。読み上げ名「Inchly ホーム」。
- 中：`nav[aria-label="サイト"]` のリンク：時間割 `#f-plan`／タイマー `#f-timer`／記録 `#f-record`／友だち `#together`／画面 `#screens`／おうちの方へ `#safety`。「画面」に NEW バッジは付けない。
- 右：テーマ切り替え `.theme`（ボタン3つ：白 `data-set-theme="white"`、紙 `"paper"`、暗い `"dark"`。アイコンは REFERENCE 6.3 の8×8 のピクセル SVG と同じ考えで自作）＋ インクのボタン `a.btn.btn-ink.btn-sm[href="#soon"]`「近日公開」（とまり木 `.perch`）。
- 住人：目ざまし時計 `ジリ` がナビの下端（72%）から糸でぶら下がる。

### hero `#top`
1. リボン `.ribbon`（燕の尾、揺れる）：「iPhone の勉強アプリ · 近日公開」。両端を折り鶴 `つる` と芽 `めぶ` が持ち上げる（`do="hoist"`）。
2. 大ロゴ `.wordmark > canvas#mark`（C が描く。`role="img" aria-label="inchly"` は外の div に）。えんぴつ `ペンタ` が字の輪郭を歩く。
3. 2列の格子（左 1.08fr／右 .92fr、下そろえ）
   - 左
     - h1：「勉強した時間が、<br>毎日<em>つみ上がる</em>。」（em はライムのマーカー）。1行目の右端に芽 `めぶ` が座って本を読む（`do="sit"`）。
     - サブ文：「時間をはかって、記録して、友だちと見せ合える。やった日はマスが緑に、続けた日数は炎といっしょに数える。小学生から受験生まで使える、iPhone のアプリです。」
     - ボタン：主 `a.btn.btn-lime.perch[href="#screens"]`「画面を見てみる ↓」／ゴースト `a.btn.btn-ghost.perch[href="#how"]`「使い方 ↓」
     - ヒント行 `.hint`：`<kbd>つつく</kbd> と反応する。<kbd>つかむ</kbd> と投げられる。ボタンに近づくと、鶴が飛ぶ。` ＋ 呼び出しボタン `button.spawn[data-spawn="pen"]`「＋えんぴつ」・`[data-spawn="flame"]`「＋ほのお」・`[data-spawn="eraser"]`「＋けしごむ」（一度呼ぶと `[data-spawn="clear"]`「かたづける」が出る）。
     - 状況の行 `.status`：「公開予定：[公開日] · <a href="#safety">保護者の方へ →</a>」
   - 右：黒い窓 `.window`（ランプ3つ、ファイル名「きょう.log」、右下に 8px のライムの影）。中身（等幅、色分け）：
     ```
     // 1. 時間割から、始める
     17:00 ▶ 英語 長文読解
     // 2. 止めたら、記録
     17:39 ✓ 英語 39分   +70 EXP
     // 3. 草がのびる
     今日 2時間45分   ▲1:17 昨日より
     ```
     色：コメント `#8d84a0` 斜体、時刻 `--sun`、科目と内容 `#ff8fa3`、分と EXP と ▲ は `--lime`、ほか `#e8e3f3`。窓の下に小さく「見本の記録です」（muted、12.5px）。ノート `ふせん` が窓の上のふち（74%）からのぞく（`do="peek"`）。
4. 現れる順番（REFERENCE 7.2）：リボン→大ロゴ→h1→サブ文→ボタン→ヒント→窓。

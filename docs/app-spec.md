## 1. コンセプト

**「GitHubみたいに勉強を管理する」アプリ。**
科目＝リポジトリ、勉強の記録＝コミット、毎日の勉強量＝草（コントリビューショングラフ）。
そこに Apple Music のように「科目をアルバムとして集める」楽しさと、仲間・ランキング・情報共有の場を足す。

### 届けたいこと
- 勉強を**見える化**して、積み上がっていく実感を持てる
- **次に何をやるか**が常にわかる（ToDo・模試や入試の日程）
- **一緒に頑張る人**がいる（ランキング・ライブ・グループ・つぶやき）
- 勉強の先にある**ワクワクする未来**に触れられる（ひとやすみコーナー）

### 対象ユーザー
- メイン：高校生・受験生（大学受験）
- サブ：中学生、大学生、資格試験を受ける社会人

### 開発方針
- 最初から全部入りで作り込む（段階リリースにはしない）。例外は金銭支援で、法律面を確認してから追加する
- 最初は日本語のみ、iPhoneのみ

## 2. デザイン方針

**メインの参考**：[`docs/design/reference-glass.jpg`](design/reference-glass.jpg)（パステルのオーロラ背景＋すりガラスのカード）。レイアウトと雰囲気はこれに合わせる。
補助の参考：GPTで作ったモックアップ4画面、参考動画（glide）、Apple Music風アプリ。

| 項目 | ルール |
|---|---|
| 全体 | 静かで上品、情報の密度は高め。トレード画面のような「計器」っぽさと、パステルのやわらかさを両立する |
| 背景 | 画面全体にパステルのオーロラグラデーション（ピーチ `#F7DFD0`、ラベンダー `#DCD9F2`、淡い水色 `#D7E6F6`、淡いピンク `#F4DCE2`）。ゆっくり溶け合うように配置し、細かい粒子感を少し乗せる |
| カード | すりガラス：半透明の白（不透明度 50〜60%）＋背景ぼかし、白いヘアライン（0.5〜1px）の縁、内側に薄い光。角丸 24〜28px、影はごく薄く |
| 文字の色 | メインは深い紫紺 `#1E1A33`（純粋な黒は使わない）。補助はくすんだグレー紫 `#9A97A8` |
| 大きな数字 | 太く大きいジオメトリック体で主役にする。単位や細かい部分はグレーで小さく（例：**2h** `45m`、**$54**`.00` の形） |
| ラベル | 等幅フォントの英大文字＋広めの字間（`TODAY`、`STREAK`、`RANKING`）。GitHub・ターミナルっぽさを出す |
| チップ | 小さなピル型。状態ごとに淡い色を敷く：プラス・達成は緑 `#12A06A`、マイナス・注意は赤 `#E5484D`、強調は紫紺の塗り |
| ライブ表示 | すりガラスのピルに緑の点＋`LIVE`＋等幅の時間（`LIVE 00:45 / 3H`） |
| グラフ | 細い線、点線の目標ライン、値はタグ（小さな角丸の札）で表示。塗りは淡いグラデーション |
| 集めるもの | 「?」マークの空きスロットを並べ、達成すると埋まっていく（`0/5` の形） |
| 草 | GitHubの5段階グリーン `#EBEDF0` → `#9BE9A8` → `#40C463` → `#30A14E` → `#216E39`。すりガラスの上でも映えるよう、空のマスは半透明の白 |
| Apple Music感 | 科目ごとのジャケット風カバー、横スクロールの棚、勉強中は再生中画面のように背景にジャケットの色をにじませる、画面下のミニプレーヤー |
| アイコン | 角丸スクエアのアプリアイコンを画面左上に置き、横にアプリ名と等幅のサブラベル |
| ダークモード | 対応する。背景は深い紫紺のオーロラ、カードは暗いすりガラス |

### 参考画像の要素をこのアプリに置き換えると

| 参考画像 | このアプリ |
|---|---|
| アイコン＋「Grok Bot」＋`PERPS · LONG/SHORT` | アイコン＋アプリ名＋`TODAY · 高3 · 東大志望` |
| `LIVE 00:00 / 22H` | `LIVE 01:24 / 3H`（今日の勉強時間と目標） |
| `EQUITY` ＋ **$54**`.00` | `STUDY TIME` ＋ **2h** `45m`、その下に `▲ +32m vs yesterday` |
| `MULT` 5x〜100x のチップ | 期間の切り替え `DAY / WEEK / MONTH / YEAR`、または科目の切り替え |
| SUI のポジションカード（エントリー・TP・含み益） | 勉強中カード：科目、目標ラインまでの進捗、`SHORT 14x` の位置に `POMODORO 2/4` |
| `TRADE TAPE` ＋ 勝敗チップ | 直近の記録（コミット）の一覧＋`12 COMMITS` `86% GOAL` などのチップ |
| `BIG CLOSES 0/5` の「?」カード | 今週のベスト記録・獲得したカード・バッジのコレクション |

## 5. 機能の詳細

### 5.1 記録

#### タイマー（勉強中の画面）
- 科目を選んでワンタップで開始。ホームのミニプレーヤーからも開始・一時停止できる
- ストップウォッチとポモドーロ（25分＋5分など、長さは変更可）を切り替えられる
- **ロック画面とDynamic Islandに経過時間を表示**（Live Activity）
- 勉強中の画面は Apple Music の再生中画面のように、科目のジャケットの色を背景いっぱいに広げる
- 一時停止、−5分／＋5分、終了ボタン
- **集中モード（任意）**：勉強中はSNSなどを開けなくする（Screen Time API）。音楽・辞書などは許可リストで使える。集中モードを途中でやめても、草や連続記録が減るなどの罰は与えない

#### 記録の完了（コミット）
- 入力は「科目」と「どのToDoをやったか」の選択だけ。メモは任意
- **次にやること**：最後に「次はいつ・何をやる？」を1タップで決める（候補は「明日の同じ時間」「〇〇の後」など）。決めた内容はToDoに入り、その時刻に静かに通知する
- 完了画面は**情報を返す画面**にする：「英語 45分 / ToDo #12 を完了 / 今週3回目 / 次の復習：仮定法（6日前）」
- 手入力（タイマーを使わなかった勉強）と、前日分の後からの入力もできる。ただし手入力した時間はランキングの対象外（5.3）

#### 草（コントリビューショングラフ）
- 過去1年分を表示。期間（週・月・年）を切り替えられる
- 色の濃さの基準【要決定】：勉強時間で決めるか、その日に記録があったかで決めるか。おすすめは「5分以上で薄い緑、時間に応じて濃く」
- 科目ごとの草も見られる（科目の詳細画面）

#### 連続記録（STREAK）
- 「🔥 23日連続」をホームに表示
- **やさしい設計にする**（調査で「途切れた瞬間にアプリをやめる」ことがわかっているため）
  - 5分の記録でも1日に数える
  - **お休みチケット**を毎月2枚無料で配る（使った日は連続が途切れない）
  - 翌日までなら後から記録を入れられる
  - 「連続記録が途切れました」という通知は出さない
  - テスト期間・体調不良などの理由を残せる
- お休みチケットは**課金で売らない**

#### 科目（リポジトリ）
- 科目ごとにジャケット風のカバー（色と大きな文字のグラフィック）。自分で色・文字を選べる。サブスクで特別なデザインを解放【要決定】
- 科目ライブラリは Apple Music のライブラリ風：ピン留めした科目の棚＋全科目のリスト（各行に直近14日のミニ草）
- 科目の詳細：目標メモ（README）、ToDo、記録の履歴（コミットの一覧）、勉強時間の合計、正答率、使っている問題集
- **目標メモ（README）**：「この勉強は誰のため・何のためか」を一行書ける（任意）。ひとやすみコーナーで気に入った記事を貼り付けられる

#### 問題集・正答率・復習リスト
- 問題集を**バーコードで登録**（ISBNから書名・表紙を取得）。手入力も可
- 問題番号またはページごとに **○・△・×** をつける
- 正答率を問題集・単元・科目ごとに表示し、推移をグラフにする
- **×と△の問題は自動で復習リストに入る**。1日後・3日後・1週間後・1か月後に復習の時期を知らせる（間隔をあけた復習）
- 復習で○になった問題は、間隔を延ばしてから卒業

#### 模試の結果
- 模試ごとに点数・偏差値・判定を入力
- 偏差値と判定の推移をグラフにする（科目別・総合）
- 結果は最初は本人だけが見られる（公開設定で変えられる）

### 5.2 計画

#### ToDo（Issues）
- 科目ごとのやること。例：「ターゲット1900 Section 3」「青チャート 数II 例題40〜60」
- 状態は未完了・完了。期限・優先度・模試や入試とのひも付けができる
- 記録の完了時に「どのToDoをやったか」を選び、終わったら完了にする
- ホームには「今日のToDo」を表示する
- 1回の勉強で終わるくらいの大きさに分けるよう、作成画面で例を出す

#### 模試・入試の日程（Milestones）
- **志望校を登録**すると、その大学の出願期間・試験日・合格発表日がカレンダーに自動で入る
- **受ける模試を選ぶ**と、模試の日程と申込締切が入る（河合塾、駿台、ベネッセ、東進など）
- 定期テスト・英検・TOEICなどは自分で追加できる
- ホームにD-dayを表示（「共通テストまで 97日」）。ロック画面ウィジェットにも表示
- 模試や入試にToDoをひも付けて、「残り12日・ToDo 12個中7個完了」と進捗を出す
- 通知は**申込締切と出願締切の数日前だけ**
- 日程データは運営が集めて毎年更新する。最初は主要大学・主要模試に絞る【要決定：対象範囲】

### 5.3 みんな

#### ランキング
- **順位あり**。自分の順位を公開するかどうかはユーザーが選ぶ（7章）
- 区分：全国 / 学年別 / 志望校別 / 科目別
- 期間：今日 / 今週 / 今月
- 指標：勉強時間 / 連続日数 【要決定：正答率のランキングも入れるか】
- **週ごとのリーグ**：近い勉強時間の30人ずつでグループを作り、週の終わりに上位は昇格・下位は降格する。上位が固定されて大多数に関係なくなるのを防ぐ
- ランキングの人をタップすると、その人のプロフィール（公開している範囲）が見られる
- 不正対策は8章

#### 比較（他の人と比べてどのくらい勉強しているか）
- **上位◯%**：「今週の勉強時間：同じ志望校の中で上位18%」。全国・学年・志望校・科目で切り替える
- **分布グラフ**：全員の勉強時間の分布の中に「あなた」の位置を表示する
- **平均との差**：「同じ志望校の平均より +3.2時間/週」。科目ごとにも出す
- **合格者ペース**：去年その大学に合格した人が、同じ時期にどれだけ勉強していたかと比べる。データが1年分たまってから表示する
- **過去の自分との比較**：先週・先月・去年の同じ時期の自分と比べる
- 人数が少ない区分（30人未満【要決定】）は、上の区分（全国など）に切り替えて表示する

#### 他のユーザーの勉強時間を見る
- **プロフィール**：草、今日・今週・今月の勉強時間、科目の内訳、使っている問題集、志望校、自分のカード
- **フォロー**：フォロー中の人の「今日の勉強時間」の一覧と、今勉強中かどうか
- どこまで見えるかは相手の公開設定に従う（7章）

#### ライブ（今勉強している人）
- 「今 1,284人が勉強中」「英語を勉強中 312人」「同じ志望校 18人」
- 勉強中の人の一覧（アイコン・科目・経過時間）。フォロー中の人は上に出す
- 勉強中に自分を表示するかどうかは、勉強のたびに切り替えられる
- カメラや音声は使わない

#### グループ・チャット
- 誰でもグループを作れる（定員は【要決定】、例：最大50人）。公開グループと招待制グループ
- グループ内のランキング、メンバーの今日の勉強時間、グループの合計
- グループ内チャット：テキスト、スタンプ、画像（ノートの写真など）
- 知らない人との1対1のDMは**作らない**か、相互フォローに限定する【要決定】（6章）

#### つぶやき
- 目的：**今勉強している人同士のコミュニケーションと、良い情報を広めること**
  - どんな問題がこの大学の入試に出そうか
  - どこの塾がいいか
  - どのYouTube動画がわかりやすいか
  - その他、勉強にまつわることなら何でも
- タブ：**最新** / **人気**
- 投稿にタグを付けられる：大学、科目、問題集、塾、種類（質問・情報・雑談・おすすめ動画）
- 反応：いいね、**「役に立った」**。人気順は「役に立った」を重く数えて並べ、勉強時間の自慢より情報が上に来るようにする
- 返信、引用、保存、シェア
- 大学・塾・問題集のページに、そのタグが付いた投稿を表示する
- YouTubeのリンクはカード表示（サムネイル・タイトル）
- 安全対策は6章

### 5.4 さがす

#### 大学情報＋マップ
- 大学の基本情報、学部・学科、入試日程、偏差値の目安、キャンパスの所在地
- **マップ**：キャンパスの位置を地図に表示。現在地や地域から探せる（MapKit）
- 大学ページに表示するもの：入試日程（ワンタップで自分のカレンダーに追加）、この大学を志望しているユーザー数、合格体験記、関連するつぶやき、関連するひとやすみ記事
- 志望校として登録できる
- 大学データの集め方【要決定】：公開情報から運営が作るか、データ提供会社と契約するか

#### 塾情報
- **登録してくれた塾をアプリ内に掲載**する
- 掲載内容：塾の名前、教室の所在地（マップ）、対象学年、コース、料金の目安、特徴、問い合わせ先
- 塾が使う管理画面（Web）で、塾の担当者が自分で情報を更新する
- 有料掲載の場合は**「PR」の表示を必ず付ける**（ステマ規制）
- 塾ページにはその塾のタグが付いたつぶやきも表示する。塾関係者による自作自演の投稿を防ぐため、塾の公式アカウントには「公式」マークを付ける
- 料金体系【要決定】：無料掲載＋有料プラン、成果報酬（問い合わせ1件ごと）など

#### 合格体験記・先輩のテンプレ（Fork）
- 合格した人が、使った問題集・勉強時間の推移・スケジュールを公開できる
- **テンプレとしてコピー**できる：科目・問題集・ToDo・模試の予定をそのまま自分のアプリに取り込む（勉強時間の記録はコピーしない）
- 運営が作る公式テンプレも用意する（共通テスト、英検、TOEIC、簿記など）

#### ショップ
- 売るもの【要決定】。候補：自分のカードのデザイン・ホロの種類、科目カバーのデザイン、アプリのテーマ、オリジナル文房具などの実物
- デジタル商品はAppleのアプリ内課金を使う
- 実物を売る場合は特定商取引法の表記と配送の仕組みが必要

### 5.5 マイページ

#### 自分のカード
- 名前（ハンドルネーム）、アイコン、志望校、草、勉強時間の合計、連続日数、称号などが載るカード
- **ホロ加工はサブスク特典**。iPhoneを傾けると光が動く（加速度センサー）
- 画像として保存・SNSに共有できる
- 表示する項目は公開設定に従う

#### 統計・グラフ
- 勉強時間：日・週・月・年の推移、時間帯ごと、曜日ごと
- 科目ごとの勉強時間（割合と推移）
- 正答率の推移（科目・問題集・単元）
- 模試の偏差値の推移
- 目標（1日の目標時間など）に対する達成率

#### 週間レポート
- 毎週日曜の夜に作る：今週の勉強時間、科目の内訳、完了したToDo、順位の変化、正答率、来週の模試・入試
- 「来週やること」を3つ決める画面につなげる
- カード画像にしてSNSやつぶやきに共有できる

#### プロフィール・フォロー・公開設定
- ハンドルネーム、アイコン、学年、志望校、一言
- フォロー・フォロワーの一覧
- 公開設定は7章

### 5.6 ひとやすみコーナー

**目的**：休憩中に記事や動画に触れて、勉強の先にある「未来の自分」にワクワクしてもらう。勉強のはげましになる、小さなコーナー。

- **出てくる場所**
  - ポモドーロの休憩中に、カードが1枚そっと出る
  - ホームの下のほうに1枚
- **中身**
  - ワクワクする話：ダークマター、量子コンピュータ、深海生物、古代DNAなど、マニアックで夢のある話
  - 先輩の今：「〇〇大学 工学部2年の1日」
  - その先の仕事：「宇宙の研究者ってどんな毎日？」
  - キャンパスの短い動画
- **形式**
  - 記事：スワイプで5枚程度、1〜2分で読める。構成は「つかみ → 物語 → 触れる（シミュレーションやクイズ） → 高校のどの単元・どの大学とつながるか → まだわかっていないこと」
  - 動画：大学の公式チャンネルや研究者の講演など、選んだYouTube動画を公式プレーヤーで埋め込む。休憩中に見るので5分以内
- **志望校・学部に合わせる**：理学部志望ならダークマター、医学部志望なら脳の話、のように少し寄せる。ときどき触れたことのない分野も混ぜる
- **休憩が終わったら戻れる**：休憩終了の合図で「続きは次の休憩で」と保存し、勉強に戻す
- **保存**：気に入った記事は保存でき、科目の目標メモ（README）に貼れる
- **記事の最後**：関連する大学・学部へリンク（大学情報・マップ）
- **量**：毎日でなくてよい。週に数本、良いものだけを載せる
- **正確さ**：科学の記事は大学の研究者・院生に監修してもらう。仮説は仮説と明記する
- **大学との連携**：大学が自分たちの研究を記事として提供できる仕組み（大学向けの有料メニューにもなる）

記事のサンプル（ダークマター）：
> 1. 宇宙の物質の約85%は見えない。それなのに「ある」ことだけはわかっている。
> 2. 1970年代、ヴェラ・ルービンは銀河の外側の星が内側と同じ速さで回っていることを見つけた。見える物質だけでは重力が足りない。
> 3. （シミュレーション）見えない物質を足すと、星が銀河から飛び出さずに回り続ける。
> 4. この発見は高校物理の「円運動」と「万有引力」で理解できる。研究できる場所：東京大学 Kavli IPMU、名古屋大学 など。
> 5. 正体はまだ誰も知らない。有力な説では、今この瞬間も暗黒物質の粒子があなたの体を素通りしている。

## 6. 安全・モデレーション

中高生が使うアプリなので、最初から入れる。App Storeの審査（ユーザー投稿のあるアプリ）でも必須。

| 対策 | 内容 |
|---|---|
| 通報 | すべての投稿・コメント・チャット・プロフィールから通報できる |
| ブロック・ミュート | ブロックした相手からは何も見えず、何も届かない |
| NGワード・画像のチェック | 投稿時に自動でチェックする（個人情報、誹謗中傷、出会い目的、性的な内容） |
| 個人情報の保護 | 学校名・本名は最初から非公開。投稿に電話番号・住所・LINE IDなどが含まれていたら警告する |
| DMの制限 | 知らない人との1対1のDMは作らないか、相互フォローに限定する。大人のユーザーから中高生へのDMは送れなくする【要決定：年齢の確認方法】 |
| 運営の監視 | 通報を処理する体制（担当者・対応時間）。悪質なアカウントの停止 |
| 塾関係者の投稿 | 塾の公式アカウントには「公式」マーク。塾が身元を隠した宣伝をした場合は停止 |
| 年齢 | 13歳未満は保護者の同意が必要【要決定】 |

## 7. 公開設定

### 項目ごとの設定

項目ごとに **全体に公開 / フォロワーだけ / 非公開** を選ぶ。

| 項目 | 最初の設定 |

| 学校名 | 非公開 |

### ルール
- ランキングの順位を非公開にした人は、ランキングの一覧に名前が出ない。本人には自分の順位が見える
- **非公開にした人の勉強時間を、平均・分布・上位◯%の計算に匿名で含めるか**【要決定】。含めるのが一般的で、統計の精度も上がる。含める場合は利用規約とプライバシーポリシーに書く
- 中高生の身元につながる情報（学校名、本名、顔写真、位置）は、本人が選んだときだけ公開する。位置情報はどの場合でも公開しない

## 8. 不正対策（ランキングと比較の信用を守る）

- ランキング・比較の対象は**アプリのタイマーで測った時間だけ**。手入力・後から入れた時間は、自分の統計と草には入るがランキングには入らない
- ありえない記録は自動で除外する（例：1日20時間以上、休憩なしの長時間）
- タイマー中はときどき「勉強中ですか？」の確認を出す（例：90分ごとに1タップ）【要決定】
- タイマーを動かしたままスマホを長時間触らない状態が続いたら一時停止する【要決定：判定方法】
- 不自然な記録は通報できる
- 同じ人の複数アカウントを防ぐ（電話番号やApple IDでの認証）

## 12. あとで追加する機能

### 金銭支援
- 目的：このアプリを通じて、家庭の事情で勉強代に困っている学生が支援をお願いできるようにする
- 後回しにする理由：
  - アプリがユーザー間のお金の受け渡しを仲介すると、資金決済法（資金移動業の登録）が関わる可能性が高い
  - 事情を偽った寄付詐欺や、未成年がお金を受け取る問題がある
- 進め方の候補：
  1. 給付型奨学金（JASSO、高等教育の修学支援新制度、民間の財団）の検索と申し込みの案内から始める
  2. 既存のクラウドファンディングや寄付のプラットフォームと連携する
  3. 運営が基金を作り、審査して給付する
- 正式に進める前に弁護士に相談する

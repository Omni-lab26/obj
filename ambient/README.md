# Ambient

背景を流すだけのアプリ。全画面で動く背景を眺めるだけ。画面をタップすると下に背景の切り替え、左上にペン、右上に設定のボタンが出ます（数秒で消えます）。

| 背景 | 内容 | タップすると |
| --- | --- | --- |
| **Koi** 夜の鯉 | 黒地の細かいグリッドに、文字で描いた錦鯉（紅白・昭和・黄金・浅黄など）と蓮の葉・蓮の花 | エサが落ちて鯉が寄ってくる。蓮の葉は波で揺れる。鯉どうしは近づきすぎず、時計のある真ん中にたまらないように池全体に散らばって泳ぐ |
| **Shallows** 浅瀬のサメ | 白地の細かいグリッドに、文字で描いたシュモクザメやトラフザメ | エサが落ちてサメが寄ってくる |
| **Blank** 白紙 | 何もない一枚の紙。時計やタイマーだけを見たいときに | — |
| **Passersby** 通りすがり | すりガラスの床を下から見上げた景色。靴底だけがくっきり（スニーカー・ランニング・革靴・ブーツで靴裏の形と溝が違う）、脚と体は網点のぼかしで歩き回る。立ち止まって足をそろえたり、その場で向きを変えたり、人をよけたりする。トラッカーのタグ付き | 近くの人が驚いて向きを変え、早足で離れる |

## 時計と設定

- 画面の中央に時計が出ます。**画面のどこかを長押し**すると、ウィジェットのように表示／非表示を切り替えられます。
- **数字を左右にスワイプ**で **時計・タイマー・ストップウォッチ** をぐるぐる切り替えられます（端はありません）。指に吸い付いて動き、離すと iPhone のページめくりのように跳ね返りなしでぴたっと止まります。入ってくるページには最初から数字の上にモード名が出ていて、止まったあと数秒で消えます。続けて素早くはじいても、1 回ごとに 1 ページずつ進みます。
  - タイマー: 横の2本の目盛りで時間を合わせます。上が時間（0〜23）、下が分・秒（1目盛り＝15秒、0:00〜59:45）。目盛りには端があり、端を越えて引くと少したわんで戻ります。目盛りを動かしている間、数字はスロットのリールのように目盛りと一緒にくるくる回り、止まった時間でぴたりとそろいます。目盛りの後ろも、数字と同じく背景になじむぼかしです。左右にドラッグ、はじくと iPhone のスクロールのように慣性でしばらく滑ってから、時間は1時間・分は1分ごとにカクっと止まります（ゆっくり離すと1目盛り単位）。1時間・1分ごとに軽く振動して（5分ごとは少し強め）、ドラッグ中も区切りで少し引っかかる手応えがあります。数字は 00:00:00 の形で桁の幅と大きさが固定なので、カウント中に揺れたり大きさが変わったりしません。数字をタップで開始／一時停止、長押しでリセット（数字も目盛りも 0 に戻ります）。時間になると振動して知らせます
    - 目盛りの下に保存枠が 5 つあります。空き枠（＋）をタップでいまの時間を保存、保存した枠をタップでその時間に、長押しで削除
  - ストップウォッチ: 数字をタップで開始／一時停止、長押しでリセット
  - どちらもアプリを閉じても時間は進み続けます
- **数字の位置と大きさ**（時計・タイマー・ストップウォッチ共通）: 左上のペンを押すと編集になります（目盛り・保存枠・下のボタン・設定は隠れます）。1 本指でドラッグして移動、2 本指でつまんで大きさ（1 本指で動かしている途中に 2 本目を置けば、そのまま大きさを変えられます）。点線は数字（日付が出ているときは日付も）をいつも囲みます。大きさが変わるのは数字だけで、日付やヒントの文字は元の大きさのままです。「リセット」で元の位置と大きさに（すっと戻ります）、「完了」で終わり。数字を囲む点線も含めて、画面からはみ出す位置・大きさにはなりません。横画面では数字の幅は画面の 2/3 までで、それ以上に広げようとすると点線が紅色になって振動します。位置と大きさは縦画面・横画面で別々に覚えていて、スマホを回すと画面に収まったまま、それぞれの配置へすっと移ります
- 日付・数字・ヒント全体の後ろに、1 枚のぼかしが入っています（暗い背景では少し暗く、明るい背景では少し明るく）。数字の幅いっぱいまでは同じ強さで、その外へだんだん薄れて背景になじむので、縁はありません（Android はぼかしの代わりに淡いベール）
- 右上の設定（スライダーのアイコン）から:
  - 時計の表示、日付、秒（時計の秒）、24時間表示
  - 時計のフォント（標準・セリフ・まる・グロテスク・コンデンス・モノ・ドット・ターミナル）
  - **色**: 横に色、縦に白〜黒が並んだ面を触って数字の色を選べます。「自動」の横にいまの時刻が時計と同じフォントで出ていて、面をなぞるとその色にそのまま変わります。「自動」で背景に合わせた白か黒に戻ります
  - **デジタルレイヤー**: 写真の背景にかかる加工の強さ。左端「素」は元の写真そのまま、右端「デジタル」は加工が最大（写真の背景があるときだけ表示）
- 設定と最後に見ていた背景は保存され、次に開いたときもそのままです。

## iPhone / Android で見る（Expo Go）

1. スマホに **Expo Go** を入れる（App Store / Google Play）
2. PC に Node.js 22 以上を入れる（`node -v` で確認）
3. PC でリポジトリを取ってきて実行

   ```bash
   git clone -b claude/clever-goldberg-bsnbxb https://github.com/Omni-lab26/obj.git
   cd obj/ambient
   npm run live
   ```

4. 出てきた QR コードを iPhone はカメラ、Android は Expo Go で読み取る

`npm run live` は、最新の取り込み → 必要なら `npm install` → 背景の書き出し → Expo の起動までをまとめて行います。起動したままにしておくと、このブランチに新しい変更が届くたびに 20 秒以内に自動で取り込み、スマホのアプリもそのまま更新されます（パッケージが変わったときは入れ直して Expo を起動し直します）。手元でファイルを変更しているときは、自動の取り込みは止まります。

| コマンド | 使いどころ |
| --- | --- |
| `npm run live` | PC とスマホが同じ Wi-Fi（WSL の中で動かしているときは自動でトンネル） |
| `npm run live -- --tunnel` | 別のネットワークでもつなぐ（トンネル経由） |
| `npm run live -- --lan` | WSL でも同じ Wi-Fi で直接つなぐ |
| `npm run live -- --no-pull` | ブランチを追いかけない |
| `npm run live -- --clear` | Metro のキャッシュを消してから起動 |

## ブラウザで背景だけ見る

`scenes/koi.html` などをそのままブラウザで開けば、アプリなしで背景だけ動きます。
`scenes/photo.html?image=<画像URL>&effect=ascii&amount=0.7` で写真の加工も試せます（effect は `scenes/shared/effects.js` の名前）。

## 背景を追加・調整する

- 動く背景は `scenes/*.html` に 1 ファイルずつ。共通部分は `scenes/shared/`
  - `host.js` — 画面サイズ・フレームループ・一時停止・タップと長押し・アプリへの通知
  - `ascii-sea.js` — 文字グリッドの魚エンジン（鯉とサメで共用、蓮の葉もここ）
  - `digital.js` / `effects.js` — 写真にかけるデジタル加工（WebGL）。`amount` 0 で元の写真、1 で最大
- 写真の背景は `scenes/photos.json` に 1 件ずつ（画像URL・焦点・加工のレシピ・タイトル・クレジット）。MVP では空にしてあり、作った 5 つ（オーロラ・桃色の雲・夕焼け・星空・ひとすじの雲）は `scenes/photos.later.json` に置いてあります。戻すときは中身を `photos.json` に写すだけです
- `catalog/backgrounds.json` に、集めた背景候補 2,065 枚と 1 枚ずつのレシピ（加工の種類・強さ・色・動き・狙いのメモ）があります。気に入ったものを `photos.json` に写せばそのまま背景になります（メトロポリタン美術館の画像は直接は読み込めないので、自分のサーバーに置き直してから）
- `npm run scenes` で `src/scenes.generated.ts` に書き出され、アプリに入ります（`npm start` でも自動で実行）
- 新しい動く背景を追加したら `src/scenes.ts` にタイトルと背景色を 1 行足す
- 魚の形を調整するときは URL の末尾に `#lineup` を付けて開くと、全部の魚が横一列に並んで止まります
- `#seed=123` を付けると乱数が固定され、毎回同じ動きになります（見比べ用）

アイデアや調査のメモは [MEMO.md](./MEMO.md) にあります。

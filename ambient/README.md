# Ambient

背景を流すだけのアプリ。全画面で動く背景を眺めるだけ。画面をタップすると下に切り替えボタンが出ます（数秒で消えます）。

| 背景 | 内容 | タップすると |
| --- | --- | --- |
| **Koi** 夜の鯉 | 黒地のグリッドに、文字で描いた錦鯉（紅白・昭和・黄金・浅黄など）が泳ぐ | エサが落ちて鯉が寄ってくる |
| **Shallows** 浅瀬のサメ | 白地のグリッドに、文字で描いたシュモクザメやトラフザメが泳ぐ | エサが落ちてサメが寄ってくる |
| **Passersby** 通りすがり | 見えない人の靴と脚のブレだけが網点印刷のように歩き回り、トラッカーのタグが付く | 近くの人が驚いて逃げる |

## iPhone / Android で見る（Expo Go）

1. スマホに **Expo Go** を入れる（App Store / Google Play）
2. PC でこのフォルダを開いて実行

   ```bash
   cd ambient
   npm install
   npx expo start
   ```

3. 出てきた QR コードを iPhone はカメラ、Android は Expo Go で読み取る

PC とスマホが別の Wi-Fi のときは `npx expo start --tunnel` を使ってください。

## ブラウザで背景だけ見る

`scenes/koi.html` などをそのままブラウザで開けば、アプリなしで背景だけ動きます。

## 背景を追加・調整する

- 背景は `scenes/*.html` に 1 ファイルずつ。共通部分は `scenes/shared/`
  - `host.js` — 画面サイズ・フレームループ・一時停止・タップ・アプリへの通知
  - `ascii-sea.js` — 文字グリッドの魚エンジン（鯉とサメで共用）
- `npm run scenes` で `src/scenes.generated.ts` に書き出され、アプリに入ります（`npm start` でも自動で実行）
- 新しい背景を追加したら `src/scenes.ts` にタイトルと背景色を 1 行足す
- 魚の形を調整するときは URL の末尾に `#lineup` を付けて開くと、全部の魚が横一列に並んで止まります

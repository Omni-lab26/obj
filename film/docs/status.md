## 完成版（1080p）

| ファイル | 内容 |
|---|---|
| `out/seimei-no-kiseki_1080p.mp4` | 完成版（曲入り、1920x1080 / 24fps / H.264 / AAC 48kHz） |

動画ファイルは容量が大きいため Git には含めず、`make` で再生成する。

- 4K 版は作っていない。CDN から取得できた 4K 素材が一部に限られ、全 43 ショットで 2160p をそろえられないため（無理な拡大はしない方針）。
- 曲はユーザー提供の音源（個人鑑賞用）。公開する場合は権利者の許諾、または投稿先の公式音源を使う。

## 当初案から変えた点

- 尺は曲に合わせた（2分13秒）。
- 素材は Pexels の公開 CDN から ID 指定で取得（API キーが発行停止中のため）。Web 検索の回数上限により、
  一部のショット（顕微鏡の微生物、ストロマトライト、河川の分岐、翅脈、カエル、クジラ、イルカ、ゾウ）は素材が見つからず外した。葉脈とハチドリは CDN の実ファイルが 720p だったため外した。
  置き換え・削除の詳細は `docs/concept.md`。
- 宇宙から見た地球は CG（再現）。クレジットに明記。

## 追加でできること

- 外したショットの素材探し（検索回数の上限が戻れば再検索できる）
- 実録音の環境音への差し替え（`work/amb_override/<タグ>.wav`）
- 4K 版（2160p 以上の素材だけで組み直す場合）

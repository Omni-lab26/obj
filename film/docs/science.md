# 科学的な扱いと出典

本作は地球史・生命史を「説明」する作品ではなく、映像と音楽で感じてもらう作品である。
そのため画面に出す事実は最小限にし、出すものは出典と整合させる。

生命誕生の年代は画面に出さない。研究によって幅が大きいため（下記）。

## 章ごとの事実と映像の関係

### 第1章 始まり（比喩）

- 形成直後の地球は、天体衝突とマグマの海を経て冷え、水蒸気が雨となって海ができたと考えられている [3][4]。
- 西オーストラリア・ジャックヒルズのジルコン（約43.7億年前に結晶化）の化学組成は、地表に液体の水が早くから存在した可能性を示す [5][6]。
- **映像**: 現在の火山・溶岩・海は、若い地球の熱と水の **比喩**（`kind: metaphor`）。当時の地球の実写記録ではない。

### 第2章 生命の芽生え（現生の微生物の観察）

- 生命の起源の年代には幅がある。
  - 日本の教科書や国立科学博物館の展示では「約40億年前に生命が誕生した」とされることが多い [3][4]。
  - 比較的よく知られる最古級の生命の証拠は、西オーストラリア・ピルバラのドレッサー層（約34.8億年前）のストロマトライトなど。ただし生物起源かどうかには今も議論がある [8][10]。
  - 全生物の共通祖先（LUCA）を約42億年前（40.9〜43.3億年前）と推定する2024年の研究があるが、年代推定にはなお議論がある [7]。
- **映像**: 温泉の微生物マット、ストロマトライト、顕微鏡下の微生物は **現在生きている微生物の実際の観察**。初期生命そのものではない。
  ストロマトライトは、最古級の化石記録と同じ種類の構造を、現在の微生物群集がつくっているものとして使う。

### 第3章 広がる生命（現生種の観察）

- 大気中に酸素が増えた「大酸化イベント」は約24億〜23億年前 [12]。カンブリア紀の始まりは約5億3880万年前（国際年代層序表 2024年版）[11]。
- **映像**: 登場する生物はすべて現生種。年代表示は付けない（「5億年前のクラゲ」のように見せない）。
- **枝分かれ**: 進化は「はしごを登るような進歩」ではなく、枝分かれして多様化する木のようなもの。どの生物も環境に「十分に」適応した結果であり、より高等・下等という序列はない [9][13]。
  本作では、河川の分岐 → 葉脈 → 翅脈の連鎖で枝分かれを示し、人間を到達点として置かない（人は登場させない）。

### 第5章 すべてがつながる（現生の観察）

- 陸上植物の種の8〜9割程度は菌根菌と共生している（定義や調査対象によって80〜94%）[14]。
- 菌類による分解（倒木・落ち葉）は、死んだ生物の物質を土に戻し、次の生命へつなぐ。
- **映像**: 雨・水・土・菌類・植物・動物。説明の文字は付けない。

## 曲に関する事実（構成の参考）

- 「Can You Hear the Music」（Ludwig Göransson、映画『オッペンハイマー』サウンドトラック 2曲目）。アルバム版は約1分50秒 [15][16]。
- 6音の音階によるバイオリンの音型が、下降するたびに速く、上昇するたびに遅くなりながら全体として加速する。テンポの変化は計21回で、終わりは始まりのおよそ3倍の速さ [17][18]。
- 本作では、この加速を「目に見える生命の密度・運動量が増していく」流れに対応させる（docs/concept.md）。
  一本道の「進歩」の比喩にはしない。

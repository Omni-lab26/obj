# 生命の軌跡 — 地球が紡いだ奇跡　企画・構成

## 核

> 私たちが目にしている自然は、途方もない時間をかけて受け継がれてきた生命の姿である。

観終わったあと、壮大な地球の美しさに圧倒され、足もとの葉や水滴まで愛おしく感じる。
感情の流れは **好奇心 → 驚き → 高揚 → 静かな感動**。

ナレーションは入れない。文字は三つだけにする。

| 位置 | 文字 | 役割 |
|---|---|---|
| 冒頭（溶岩の亀裂） | 約46億年前 | 時間の物差しを一度だけ示す |
| 終盤（朝の光の若葉） | 一度も途切れることなく、／命はここまで続いてきた。 | 主題。共通祖先から現在のすべての生物まで系譜が途切れていないという事実に基づく |
| 最後（黒地） | 生命の軌跡　地球が紡いだ奇跡 | タイトル |

エンドクレジットの冒頭に「本作の映像はすべて、現在の地球で撮影された実写です」と明記する（下記「科学的な扱い」）。

## 尺と音楽

- 曲: 「Can You Hear the Music」（Ludwig Göransson、映画『オッペンハイマー』）。アルバム版は約1分50秒。
  6音のバイオリンの音型が下降するたびに速く、上昇するたびに遅くなりながら全体として加速し、
  テンポの変化は計21回、終わりは始まりのおよそ3倍の速さ（出典は `docs/science.md`）。
- 尺は曲に合わせる（ご指示「尺は気にしないで」に従い、3分に引き伸ばさない）。
  - **0:00〜0:03** 曲の前の暗闇。地鳴りと溶岩の明滅だけで始める（静けさから気配へ）。
  - **0:03〜曲の終わり** 曲をそのまま全尺で使う。ループ・編集による引き伸ばしはしない。
  - **曲の終わり〜** 余韻（第6章）。曲が止んだ後の静けさに、水滴・芽・若葉と締めの言葉、タイトル、クレジット。
  - 全長はおよそ 2分15秒〜2分20秒（曲の実測で確定）。
- 「加速し続ける曲」と「生命史」の対応:
  - 地球史の前半およそ40億年は目に見える生物がほとんどいない。最後の約5億年で目に見える多様性が一気に広がる。
    曲の加速を、映像の **生命の密度・運動量の増加** に対応させる（一本道の「進歩」ではなく、枝分かれが増えていく密度として描く）。
  - 編集のテンポも曲に合わせて上げる（第1〜2章は1カット約3秒 → 第4章は1.5秒前後）。ただし第4章にも長回し（森の空撮、ムクドリの群れ、クジラ、滝）を残し、見入る時間を作る。
  - すべてのカットを拍に合わせない。各ショットに `sync`（beat / downbeat / hit / free）を指定し、第5〜6章は `free` にして呼吸を残す。

## 構成（章と曲の対応）

章の開始位置は `data/config.json` の `chapter_anchors` で決め、曲の解析結果（構造の区切り・アクセント拍）に吸着させる。
下の時刻は曲を約110秒として組んだ仮の値。実際の曲を解析すると自動で更新される（`docs/timing_sheet.md`）。

| 2 生命の芽生え | 0:21〜0:40 | 曲の前半 | 水中に差す光 → 熱水の泡 → 温泉の微生物マット → 顕微鏡下の微生物 → 珪藻・細胞 → ストロマトライト → 暗い水中のクシクラゲ | 好奇心 |

## 形と運動の呼応（マッチカット）

関連が伝わる3か所に絞る。つなぎは6フレーム（0.25秒）のごく短いディゾルブ。

1. **枝分かれ**（第3章の終わり）: 河川の分岐（空撮）→ 逆光の葉脈 → トンボの翅脈。
   進化を一本道ではなく「枝分かれ」として示す、本作で唯一の比喩的な連鎖。構図の中心と分岐の向きをそろえる。
2. **群れの運動**（第4章）: うねる海 → 渦を巻く魚群 → ムクドリの群れ。波の進む向きと群れの回転方向をそろえる。
3. **球**（冒頭と結末の呼応）: 青い地球 ↔ 葉の上の水滴。説明はせず、形の記憶だけを残す。

その他の転換は原則としてカット。章の変わり目だけ18フレームのディゾルブ。派手なトランジション、光漏れ、意味のない粒子は使わない。

## 色と画

- 自然な深み。暗部はつぶさず質感を残し、わずかなS字カーブだけを全編共通で掛ける（`config.json` の `look`）。
- 彩度は全体を4%だけ下げる。素材ごとの露出・色温度の差は `selects.json` の `grade` で個別に補正し、極端な彩度・発光表現は使わない。
- 水中は青、溶岩は赤という被写体固有の色は残す（自動のホワイトバランスで消さない）。
- 解像度は 1920x1080 未満の素材を使わない。4K 版は全ショットが 2160p 以上の素材のときだけ作る（無理な拡大をしない）。
- フレームレートは 24fps。25/30/60fps の素材は「全コマを24fpsで再生」して、コマの重複・間引きによるカクつきを避ける（30fps は0.8倍、60fps は0.4倍のスローになる）。速さが不自然なショットは `speed` で個別に指定する。

## 科学的な扱い

- 映像はすべて **現在の地球の実写**。古代の生物の記録として見せない。
  - 第1章の火山・溶岩は「若い地球の熱」の **比喩**（`kind: metaphor`）。
  - 第2章の微生物マット・ストロマトライト・顕微鏡映像は、**現在生きている微生物の実際の観察**。初期生命そのものではない。
  - 第3章以降の生物はすべて現生種。「5億年前の生物」のような年代表示は付けない。
  - エンドクレジットの冒頭に注記を入れる。
- 年代表示は「約46億年前」の一か所だけにする。出典と表現は `docs/science.md`。
- 進化を「下等→高等」の一本道として描かない。枝分かれの連鎖（河川→葉脈→翅脈）と、第4章で多様な系統を並置することで示す。人間を到達点として置かない（人は登場させない）。

## 音

- ナレーションなし。曲 + 控えめな環境音。
- 環境音は映像に対応させる（溶岩のはぜる音、波、水中、泡、風、雨、小川、森の空気、水滴）。曲の下では約18dB下げ、曲の前後（冒頭と余韻）だけ前に出す。
- 冒頭の噴火のカットにだけ低い衝撃音を一つ置く（5秒以内の引き）。
- 曲が終わった直後は無音にせず、水滴と森の空気だけを残して余韻にする。

# 生命の軌跡 — 地球が紡いだ奇跡　企画・構成

## 核

> 私たちが目にしている自然は、途方もない時間をかけて受け継がれてきた生命の姿である。

観終わったあと、壮大な地球の美しさに圧倒され、足もとの葉や水滴まで愛おしく感じる。
感情の流れは **好奇心 → 驚き → 高揚 → 静かな感動**。

ナレーションは入れない。文字は三つだけにする。

| 位置 | 文字 | 役割 |
|---|---|---|
| 冒頭（溶岩の亀裂） | 約46億年前 | 時間の物差しを一度だけ示す |
| 終盤（朝の光の若葉） | 一度も途切れることなく、／命はここまで続いてきた。 | 主題。共通祖先から現在のすべての生物まで系譜が途切れていないという事実に基づく |
| 最後（黒地） | 生命の軌跡　地球が紡いだ奇跡 | タイトル |

エンドクレジットの冒頭に「本作の映像は、宇宙から見た地球（CGによる再現）を除き、すべて現在の地球で撮影された実写です」と明記する（下記「科学的な扱い」）。

## 尺と音楽

- 曲: 「Can You Hear the Music」（Ludwig Göransson、映画『オッペンハイマー』）。ユーザー提供の音源（110.2秒）を使用。
- 尺は曲に合わせる（2分13秒）。冒頭2秒の暗闇 → 曲を全尺 → 曲が途切れた後の余韻 → タイトル・クレジット。
- 曲の解析（`docs/music_analysis.png`, `data/music.json`）:
  - 0〜19秒: バイオリンだけ。19.05秒で低音が入り、25.05秒で低弦が加わる。
  - 31秒以降: 低音のアタックが約0.75〜1.4秒ごとに規則的に刻まれ（体感のパルス）、加速とともに間隔が詰まる。
  - 53.80秒: 最も大きなセクションの始まり。87〜101秒: 半音ずつ上がる頂点。
  - **101.48秒: 曲が急に途切れ**、残響だけが約4秒続いて消える。
- **カット割り**: 曲中のカットは低音のアタック（パルス）に吸着させる。40カット中37カットがパルスから1フレーム以内、残る3カットは意図的に別の位置に合わせた（噴火 = 和声の変わり目 4.00s、霧の木立 = 最大のアタック 55.79s、水滴 = 曲の途切れ 103.50s）。
  ショットの長さは2〜5パルス、頂点（第5章）は1パルスずつ。章の頭は曲の構造の変わり目に置く。

## 構成（章と曲の対応）

| 章 | 映像の時刻 | 曲の位置 | 内容 |
|---|---|---|---|
| 1 始まり | 0:00〜0:21 | 曲の前〜低音が入るまで | 暗闇に「約46億年前」→ 溶岩の亀裂 → 夜の噴火（曲の和声の変わり目でカット）→ 枝分かれする溶岩流 → 噴煙の火口 → 積乱雲 → 黒い岩に砕ける波 → 宇宙から見た地球（CG） |
| 2 生命の芽生え | 0:21〜0:33 | 低音・低弦が入る | 水中の光 → 間欠泉の湯だまりが膨らみはじける → 水底の藻類 → 暗い水中で光るクラゲ |
| 3 広がる生命 | 0:33〜0:56 | パルスが規則的になる | クラゲ → サンゴ礁 → ウミガメ → 擬態するタコ → 波打ち際（海から陸へ）→ 苔 → シダの林床 → **葉脈 → 枝分かれする小枝** |
| 4 生命の交響曲 | 0:56〜1:30 | 最も大きなセクション | 霧の朝の木立（長回し）→ 光芒 → ミツバチ → 蝶 → ハチドリ → **押し寄せる波 → 流れる魚群 → 光へ泳ぎ上がるタイマイ → ムクドリの群れ（長回し）** → 鳥の群れ → 夕日のカモメ → 走るシマウマ → 滑空する鳥 |
| 5 すべてがつながる | 1:30〜1:43 | 半音ずつ上がる頂点 | 葉を打つ雨 → 地面に跳ねる雨 → 渓流 → キノコ → 枯れ葉に伸びる菌 → アリ塚 → 草を食むシカ → 黄葉の森に舞う葉 → 渓谷の滝 |
| 6 余韻 | 1:43〜1:59 | **曲が途切れた瞬間**から | 葉先で膨らんだ水滴が、曲が途切れて2.5秒後に落ちる（水音をひとつ）→ 芽生え → 木漏れ日の若葉と締めの言葉 → タイトル → クレジット |

素材の都合で当初案から変えた点（Pexels の検索・取得の制約による）:

- 顕微鏡の微生物、ストロマトライト、温泉の微生物マット、河川の分岐、トンボの翅脈、カエル、クジラ、イルカ、ゾウ、逆光の葉脈、ハチドリは、利用できる素材（1080p 以上）が見つからず外した。
- 森の空撮 → 霧の朝の木立、シダの若芽 → シダの林床、猛禽 → 滑空する鳥 に置き換え、群れの流れに「光へ泳ぎ上がるタイマイ」「夕日のカモメ」を加えた。
- 宇宙から見た地球は実写が見つからず、CG（再現）を使った。クレジットの注記にも明記。

## 形と運動の呼応（マッチカット）

関連が伝わる3か所に絞る。つなぎは6フレーム（0.25秒）のごく短いディゾルブ。

1. **枝分かれ**: 第1章の枝分かれする溶岩流と、第3章の終わりのシダの林床 → 枝分かれする小枝。
   進化を一本道ではなく「枝分かれ」として示す。
2. **群れの運動**（第4章）: 斜めに押し寄せる波 → 同じ向きに流れる魚群 → 光へ泳ぎ上がるタイマイ → 空のムクドリの群れ。
3. **球**（冒頭と結末の呼応）: 青い地球 ↔ 葉の上の水滴。説明はせず、形の記憶だけを残す。

その他の転換は原則としてカット。章の変わり目だけ18フレームのディゾルブ。派手なトランジション、光漏れ、意味のない粒子は使わない。

## 色と画

- 自然な深み。暗部はつぶさず質感を残し、わずかなS字カーブだけを全編共通で掛ける（`config.json` の `look`）。
- 彩度は全体を4%だけ下げる。素材ごとの露出・色温度の差は `selects.json` の `grade` で個別に補正し、極端な彩度・発光表現は使わない。
- 水中は青、溶岩は赤という被写体固有の色は残す（自動のホワイトバランスで消さない）。
- 解像度は 1920x1080 未満の素材を使わない。4K 版は全ショットが 2160p 以上の素材のときだけ作る（無理な拡大をしない）。
- フレームレートは 24fps。25/30/60fps の素材は「全コマを24fpsで再生」して、コマの重複・間引きによるカクつきを避ける（30fps は0.8倍、60fps は0.4倍のスローになる）。速さが不自然なショットは `speed` で個別に指定する。

## 科学的な扱い

- 映像はすべて **現在の地球の実写**。古代の生物の記録として見せない。
  - 第1章の火山・溶岩は「若い地球の熱」の **比喩**（`kind: metaphor`）。
  - 第2章の間欠泉・藻類・クラゲは、**現在の自然の実際の観察**。初期生命そのものではない（顕微鏡映像は素材が得られず未使用）。
  - 宇宙から見た地球（C1-07）は CG による再現（`kind: reconstruction`）。
  - 第3章以降の生物はすべて現生種。「5億年前の生物」のような年代表示は付けない。
  - エンドクレジットの冒頭に注記を入れる。
- 年代表示は「約46億年前」の一か所だけにする。出典と表現は `docs/science.md`。
- 進化を「下等→高等」の一本道として描かない。枝分かれの連鎖（河川→葉脈→翅脈）と、第4章で多様な系統を並置することで示す。人間を到達点として置かない（人は登場させない）。

## 音

- ナレーションなし。曲 + 控えめな環境音。
- 環境音は映像に対応させる（溶岩のはぜる音、波、水中、泡、風、雨、小川、森の空気、水滴）。曲の下では約18dB下げ、曲の前後（冒頭と余韻）だけ前に出す。
- 冒頭の噴火のカットにだけ低い衝撃音を一つ置く（5秒以内の引き）。
- 曲が終わった直後は無音にせず、水滴と森の空気だけを残して余韻にする。

# 素材の検索・選定方針

## 取得元とライセンス

| 取得元 | 用途 | ライセンス | 条件 |
|---|---|---|---|
| Pexels（API） | 実写映像の主な取得元 | [Pexels License](https://www.pexels.com/license/) | 無料・商用可・帰属表示任意。改変せず単体で販売・再配布しない。人物や商標が写る素材は使わない |
| Pixabay（API、任意） | Pexels で見つからない場面の補完 | [Pixabay Content License](https://pixabay.com/service/license-summary/) | 無料・商用可・帰属表示任意。単体で再配布しない |
| 環境音 | 合成（`scripts/ambience.py`） | 自作 | 制約なし |

使わないもの:

- 透かし付きのプレビュー（API が返す元ファイルのみを使う）
- 無断転載と思われる映像（テレビ番組・映画・他社ドキュメンタリーの切り抜き、ロゴや字幕が焼き込まれたもの）
- 出所や利用条件を確認できない素材
- CC BY-SA など、作品全体に継承条件が及ぶライセンス
- 人の顔・ブランド・建物が主体になる映像（作品の主題から外れ、肖像権・商標の確認が必要になるため）

宇宙から見た地球（C1-07）は、Pexels 上のものが実写（ISS 等の撮影）か CG かを必ず確認する。
CG の場合は `kind` を `reconstruction`（図解・再現）に変えるか、ショット自体を外す。

## 選定の手順

1. `scripts/fetch_footage.py search` が、各ショットの検索語（3つ前後）で候補を集め、
   `work/sheets/<ショット>.jpg` に **候補ごとに5コマのフィルムストリップ** を並べた比較シートを作る。
2. 比較シートを見て、次の観点で選ぶ（`autopick` は解像度・長さ・検索順位だけで仮決めするので、必ず目で確認する）。
   - 画質: ピント、圧縮ノイズ、手ぶれ、白飛び・黒つぶれ、色かぶり
   - 構図: 主題の位置、マッチカットの相手と形・向きがそろうか
   - 動き: 速さ・方向が前後のショットとつながるか（例: 波の進む向き → 魚群の回転）
   - 光と色: 章の中で色温度・明るさがそろうか
   - 解像度: 1920x1080 以上（4K 版を作る場合は 3840x2160 以上）
   - 長さ: 使う尺 + 前後1秒の余白（スローにする場合はその分長く）
3. 選んだ素材を `data/selects.json` に書く（`"auto": false` にすると autopick に上書きされない）。

```json
"C4-08": {"provider": "pexels", "id": 1234567, "auto": false,
          "in": 6.5, "speed": 0.5, "crop": {"zoom": 1.05, "x": 0.5, "y": 0.45},
          "grade": {"exposure": -0.02, "saturation": 0.95}, "note": "群れの回転が右回り。C4-07 の魚群と方向をそろえた"}
```

4. `scripts/fetch_footage.py download` で取得すると、`data/manifest.json` に
   取得元URL・作者・作者URL・ライセンス・ライセンスURL・クレジット表記・解像度・fps・長さ・ハッシュ・取得日時が記録され、
   `scripts/credits.py` が `docs/credits.md` / `docs/assets.csv` / エンドクレジットを作る。

## 有料素材について

まずは上記の無料素材だけで完成を目指す。どうしても質の高い素材が見つからない場面
（例: 実写の地球全景、クシクラゲ、ストロマトライト）が残った場合だけ、
金額と用途を示して購入の可否を確認する。

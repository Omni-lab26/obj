# データ調査（第1回・2026年10月）

「政党通知表」に必要なデータが、実際にどこまで手に入るかを調べた結果。
難易度：◎ すぐ使える ／ ○ 加工すれば使える ／ △ かなり大変 ／ × 公式には手に入らない

## まとめ

| データ | 主な入手先 | 形式 | 難易度 |
|---|---|---|---|
| 国会の発言・質問 | 国会会議録検索システム API | JSON（認証不要） | ◎ |
| 衆議院の議案と会派別賛否 | 衆議院の議案審議経過ページ／SmartNews研究所のデータ | HTML／CSV・JSON | ○ |
| 参議院の議員別賛否 | 参議院「本会議投票結果」（押しボタン式投票） | HTML | ○ |
| 衆議院の議員別賛否 | 記名投票のときだけ記録される | 会議録 | △ |
| 政党交付金の配分額 | 総務省の発表 | PDF・報道 | ◎ |
| 政党交付金の使途（本部・支部） | 総務省「政党交付金使途等報告書」 | PDF | △ |
| 政治資金収支報告書（本部・議員団体） | 総務省・各都道府県選管 | 画像PDF | △ |
| 国の予算・事業ごとの支出先 | 行政事業レビュー（RSシステム）、e-Govデータポータル | Excel（CC BY） | ○ |
| 過去の公約 | 一括で使えるアーカイブはない | 各党サイト・選挙公報 | △〜× |

## 詳細

### 1. 国会の発言（◎）
- `https://kokkai.ndl.go.jp/api/` は認証不要でJSONを返す。発言単位と会議単位で取得できる
- 1回の取得件数には上限がある（会議単位の簡易出力で100件、本文付きで10件程度）。公式に「数秒間隔をあける」よう求められている
- 用途：活動量（発言数・質問数）、AIによる公約と発言の照合

### 2. 採決・賛否（○、ただし衆議院の議員個人は△）
- **衆議院**：議案ごとのページに「賛成会派」「反対会派」の欄がある。ただし表形式の一括データはない
  - スマートニュース メディア研究所が衆議院の議案データをCSV・JSONで公開している（MITライセンス、出典表記が必要）
  - 衆議院の本会議は起立採決が中心なので、**議員個人の賛否はほとんど残らない**
- **参議院**：押しボタン式投票の結果が、議員ごとの賛成・反対・投票なしまで公開されている
- **設計への影響**：議員通知表の「採決」欄は、参議院議員なら個人の賛否、衆議院議員なら所属会派の賛否で代わりに表示する、という扱いになる

### 3. 政党交付金（配分額◎・使途△）
- 2026年分の総額は約315億円、11党に配分（自民153.6億円、立憲31.2億円、維新28.2億円、国民27.2億円、中道改革連合23.4億円、参政19.9億円、公明14.0億円、れいわ7.0億円、チームみらい5.7億円、日本保守2.9億円、社民2.3億円）。共産党は制度に反対して申請していない
- 使途等報告書は本部分も支部分も総務省がネット公開している（提出年の9月30日までに公表）。2026年から官報での要旨公表は廃止された

### 4. 政治資金収支報告書（△）
- 現在は総務省と都道府県選管が**画像PDF**で公開しており、検索できない
- **公開期間は3年**（例：香川県）。過去分は自前で保存しないと消える
- 改正政治資金規正法により、2027年1月から政党本部・国会議員関係政治団体など約3,000団体（全体の約5%）にオンライン提出が義務化される。総務省は**2028年4月1日までにデータベースでの公表を始める**予定（2026年分の定期公表から対象）
- 個人寄附者などの氏名はデータベースの対象外になる方向
- **使える民間の取り組み**
  - 東京のシンクタンクが公開した無料の政治資金収支報告書データベース（2025年4月公開、PDFをデータ化したもの）
  - チームみらい「みらいまる見え政治資金」：サンキー図による可視化。オープンソース

### 5. 国の予算（○）
- 行政事業レビューのデータは府省ごとの事業・支出先単位で、e-GovにExcel（CC BY）がある。RSシステムには事業ごとの予算事業IDが付いていて、年度をまたいで追跡しやすい
- 「どの党がどの予算に賛成したか」は予算案・関連法案の会派別賛否（2.）とつなげる

### 6. 公約（△〜×）
- 過去の公約を体系的にまとめた公開データベースは見つからなかった（東大・朝日の共同調査で確認できたのは2003年の選挙公報のみ）
- 早稲田大学マニフェスト研究所が過去に各党マニフェストを採点した例はある
- 自分たちで集める必要がある：各党の公約PDF、選挙公報、ウェブアーカイブなど
- この領域は既存サービスがほぼ手を付けていないため、**差別化ポイントでもある**

## 設計への影響（要相談）

1. **衆議院議員の個人採決**は取れない → 会派の賛否で代わりに表示するか
2. **お金の過去データ**：公式公開は3年分のみ → 民間DBとの連携や自前の保存が必要
3. **お金のデータ化**：2028年の公式DB開始まではOCRとAIで読み取るしかない。公式DBを待ってから本格対応する手もある
4. **政党の合流・分裂**：2026年に中道改革連合ができたように党の形が変わるので、「政党の系譜」を管理するデータ設計が必要
5. **既存のオープンデータ・OSSとの協力**：SmartNews研究所のデータ、みらいまる見え政治資金、民間DB

## 補足：開発環境
- 現在のクラウド開発環境のネットワーク設定では、`*.go.jp`（kokkai.ndl.go.jp、soumu.go.jp など）への直接アクセスが拒否される
- データ収集スクリプトを動かすには、環境設定の許可ドメインにこれらを追加する必要がある

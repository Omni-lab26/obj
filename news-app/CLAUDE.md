## プロダクト
- 名前：Halftick（仮確定）（コード名：news-app）。bundle ID：app.halftick（案）、slug：halftick（案）。確定後は**変更禁止**（変えるときは必ず相談）
- 何のアプリか：金融・ビジネスの「NERV」。世界の一次情報と報道をAIで日英2言語にまとめ、1日4回＋速報でアプリとサイトに同時配信する。個人の投稿、コメント、グループ・個人間チャットで世界の専門職が語り合える場所
- 仕様の正：`docs/brief.md`（MVP・やらないこと）、`docs/screens.md`、`docs/design.md`、`docs/data-model.md`
- `docs/brief.md` の「やらないこと」にある機能は作らない。思いついた機能は「あとで」に書くだけにする
- 仕様を変えたら該当する docs を更新し、`docs/decisions.md` に日付と理由を書く

## 対応範囲
- iOS / Android / Web（スマホ優先）、画面幅 320〜440（それより広いときは中央に寄せる）、縦固定
- 文字サイズ 1〜2倍、ダークモード あり、タブレット iPhone の表示を拡大（いずれも brief.md 承認待ち）
- 言語は日本語・英語。画面の文言は直書きせず、翻訳ファイルから取る

## 技術のルール
- Expo SDK {58}。API は推測せず、この版の公式ドキュメントで確かめる（AGENTS.md も参照）
- パッケージは `npx expo install` で入れる
- 色・文字・余白・動きは `theme/` のトークンから取り、数値を直書きしない
- 画面幅は共通の hook から取り、`393` などの固定値を書かない
- 画面はサーバーを直接さわらず、`src/lib/data/` を通す。権限ルールはサーバー（RLS）を正とし、アプリ側に同じ判定を書かない
- Reanimated：`.value` ではなく `.get()` / `.set()`。ワークレットは作られた時点の変数をコピーして持つので、変わる値は shared value で渡す
- 言語の判定は `expo-localization`。`Intl` の既定に頼らない
- 端末に保存する設定にはバージョンを付け、項目を足したときの補い方を書く。保存キーに製品名を入れない（改名で設定が消えるため）
- MVP の外に出した機能は消さずに `src/constants/features.ts` の切り替えで隠す
- 生成物（同梱する HTML など）があるなら `prestart` で作り直す。手で作り直すことに頼らない

## 完了の条件（毎回）
1. `npm run verify`（型・lint・整形・テスト）が通る
2. 画面を変えたら `node scripts/shot.mjs <ルート>` で3つの画面幅を撮り、画像を自分で見る
3. `docs/verify.md` の「実機でしか分からないこと」に当たる変更なら、確かめてほしい点を3行で伝える
4. コミットする

## ニュースの扱い（必ず守る）
- 新聞・ニュースサイトの記事本文を取り込まない。本文を元にAI要約しない。報道は見出し＋リンク＋事実だけの自前の短文
- まとめの数字は元データから取り出す。AIに数字を作らせない
- まとめには元情報へのリンクと「AIによる要約」の表示を必ず付ける
- 特定の銘柄の売買をすすめる文を出さない

## 触ってはいけないもの
- `.env`、本番 DB（SQL はオーナーが流す）、パスワードや鍵の入力
- 他のプロジェクトのポートやプロセス。開発サーバーは :{8093} だけ使う

## 外に出す前に必ず確認する
- デプロイ、公開、送信、ストアへの提出、外部サービスの作成、有料プランの変更

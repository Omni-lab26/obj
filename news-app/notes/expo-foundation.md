2026-11-05 開始。オーナーの言葉：「expoで動かしたい実装してくれ　全体的に違和感があるとこはしっかり修正しながら」

## 動かし方（オーナーの PC で）

```bash
cd news-app
npm install
npm run live
```

- `npm run live`：見本の画像の表を作ってから起動（開発サーバーは 8093 番）
- `npm run live:tunnel`：スマホと PC が同じ Wi-Fi でないとき
- `npm run live:web`：ブラウザで開く

- スマホに **Expo Go**（SDK 58 に対応した最新版）を入れ、表示された QR コードを読む
- PC とスマホは同じ Wi-Fi に。つながらないときは `npx expo start --tunnel`
- ブラウザで見るときは `npx expo start --web`

## 見本の画像（ワイヤーと同じ画像を使う）

- オーナーの参考画像の切り抜き（27枚）は第三者の作品で、リポジトリは公開なので入れない
- 手元で使うときは、画像を `news-app/assets/ref/` に置く（例：`assets/ref/sq1.jpg`）。`npm install` / `npm start` / `npm run refs` のときに自動で読み込む表ができる
- 画像がないときは、ジャンルごとの文字組みのサムネで表示する（どちらでも動く）
- 公開する前に、自分たちの画像（または許可のある画像）に差し替える

## 目的
- 何のアプリか：**密なコミュニティと、それをまとめるアプリ。** オーナーが配信するニュースをきっかけに、経済に関心のある世界の社会人と専門職がコメントで議論する場所。扱うのは金融だけでなく、物価・仕事・エネルギー・テック・政策など**経済全体**
- 柱（いちばん大事なこと）：**オーナーが配信するニュース → みんながコメントして議論する。** これを真ん中に置く。ニュースは議論のきっかけで、価値は議論とそこに集まる人にある
- 誰の、何を解決するか：経済に関心のある世界の社会人（日本語・英語。金融の専門職から、仕事や暮らしの目線で経済を見る人まで）の「経済のニュースについて、信頼できる人と気兼ねなく語り合える場がない」を解決する
- このプロジェクトの目的：良いプロダクト（慈善に近い運営。コミュニティ次第で大きくも小さくもなってよい）
- 運営：個人（ひとり）。配信はオーナー自身が出す

## MVP
<!-- オーナー指定は5つ。1と2が柱。3〜5は柱を支える機能。部品としては「配信」「投稿＋コメント」「チャット（グループ＝N人の部屋、個人間＝2人の部屋）」の3つ。 -->
1. **オーナーのニュース配信（議論のきっかけ）**：アプリとサイトに同時に出す。元情報へのリンクを付ける。日本語と英語。**4つの種類に分け、ホームでの形・色・内容を変えて、ひと目で見分けられるようにする**
   - **公開当初の中心は「動画の深掘り」**（2026-11-05 決定）：YouTube に上げた解説動画1本ごとに、アプリでそれをより詳しく・マニアックに解説する記事を1本出す。記事の上に同じ動画を置く。回数は決めず、話題・ニュースの分だけ出す（量はしっかり確保する）
   - **定時配信**：1日4回（7:00 / 11:30 / 15:30 / 22:00）のまとめ。正方形のサムネの記事。**公開当初は出さない**（回数を決めないため。仕組みは残し、`features.ts` の切り替えで隠す。始める時期はあとで決める）
   - **速報**：大事な発表のとき。赤
   - **ひとこと**（不定期）：短い投稿（500字まで、リンクか写真1枚）。絵なしで文字が主役。青緑
   - **深掘り**（不定期）：長めの解説記事。横長の表紙と読む時間。紫
   - ユーザーの投稿は「みんな」に分け、ホームには出さない
   - お知らせは**利用者が種類ごとに選ぶ**（4つの時刻・速報・ひとこと・深掘り）
2. **コメントと議論（真ん中）**：配信ごとのコメント欄で議論する。返信のつながりが見える、リアクション、自分のコメントへの返信を通知、いま議論が盛り上がっている配信が分かる。通報・ブロック・非表示つき
3. **グループ**：招待リンクで入る少人数のグループと、その中のチャット。配信をグループに持ち込んで、仲間内で深く話せる
4. **個人間チャット**：同じグループのメンバー同士だけで始められる1対1チャット
5. **個人の投稿（サイド）**：**認証制**。運営が認めた人だけがテキスト＋リンクで投稿でき、その下でも議論できる。投稿したい人はアプリから申請し、運営が管理画面で認める

## やらないこと
<!-- 迷ったらここに足す。消すときは decisions.md に理由を書く。 -->
- イベント
- PC向けの2列表示（Web はスマホ幅で中央に寄せて表示する）
- サブスク・課金、広告（公開時は無料・広告なし）
- 新聞・ニュースサイトの**記事本文の取り込みと、本文を元にしたAI要約**（著作権リスク。報道は見出し＋リンク＋事実だけの自前の短文）
- 知らない人どうしの個人間チャット（出会い系サイト規制法・荒らし対策）
- 特定の銘柄の売買をすすめる内容（投資助言業の登録が必要になる）
- チャットでの画像・動画・ファイルの送信
- 日本語・英語以外の言語
- 個人の投稿への画像・動画の添付

## あとで（思いついたけど MVP に入れないもの）
- 個人の投稿への画像の添付
- 日本語・英語以外の言語
- イベント（オンライン → オフライン）
- PC向けの2列表示（メイン＝運営の配信、横＝個人の投稿）
- 広告（利用者が増えてから。控えめに、高レバレッジのFX・暗号資産など信頼を損なう広告は載せない）
- 応援会員のサブスク（2026-11-05 オーナーのメモ。下の「サブスクのメモ」も見る）
- 設定のあとで回し：自分のデータの書き出し、外観（ライト／ダーク）の切り替え、文字の大きさ、動きを減らす（いずれも最初はスマホの設定に従う）、動画の自動再生、メールでのお知らせ、既読を見せるか、キャッシュの削除
- 職種バッジ（証券・銀行・会計士・FP など。名乗りたい人だけ）
- 配信の間違いをユーザーが指摘して直せる仕組み
- ユーザーが情報源を提案・投票できる仕組み、ロードマップの公開
- 媒体との提携（提携できたら報道の扱いを広げる）

## 完成の基準
<!-- 確かめられる形で。柱（配信 → 議論）に関わるものを先に書く。 -->
- 配信を開いたら、その下ですぐに議論が読めて、2タップ以内でコメントや返信を書ける
- 返信のつながりが分かる形で表示され、自分のコメントに返信が付くと通知が届き、通知から1タップでその議論に戻れる
- 配信の一覧で、どの配信に議論が集まっているか（コメント数・新しいコメント）が分かる
- 配信をグループに共有でき、グループの中で続きを話せる
- （定時配信を始めたら）オーナーは 7:00 / 11:30 / 15:30 / 22:00（日本時間。UTC では 22:00〈前日〉/ 2:30 / 6:30 / 13:00）を目安に、管理画面から配信を出せる。出した配信は**アプリとサイトに同時に**載る
  - 7:00＝米国の大引け後・アジアの寄り付き前、11:30＝アジアの昼、15:30＝アジアの大引け・欧州の寄り付き、22:00＝米国の寄り付き前
- 配信は日本語と英語の両方で出る。数字と元情報へのリンクは両方の言語で同じ
- 配信の下書きに使う数字（指標・株価・金利など）は、元データの値と一致する
- 速報の対象（日銀・FRB・ECB の会合、米雇用統計、CPI など）が出たら、オーナーに下書きの準備ができたことが届き、確認して出すと利用者に通知が届く
- 投稿の権限がない人には投稿ボタンの代わりに「投稿を申請する」が出て、運営が認めると投稿できるようになる
- 個人の投稿・コメント・チャットで、通報・ブロックができ、ブロックした相手の書き込みは見えなくなる
- 個人間チャットは、同じグループのメンバーとしか始められない
- アプリの中からアカウントを削除できる
- 日本語の端末では日本語、それ以外の端末では英語で起動し、電波が悪くても配信と議論は前回の内容が表示される

## 収益と配信
- 公開時は無料・広告なし。利用者が増えてから広告を入れる（目安は公開後に決める）
- 広告の方針：控えめに。高レバレッジのFX・暗号資産など、信頼を損なう広告は載せない（案）
- 無料と有料の境目：なし（サブスクは「あとで」）
- 配信する国：全世界（画面とまとめは日本語・英語）。商標は日本・米国以外（EU など）が未確認

## 集客（アプリへの入り口）（2026-11-04 オーナーのメモ）
- 入り口は YouTube。簡単で分かりやすい動画を上げ、「この話題でいま活発に議論が行われています。続きは Halftick で」とアプリへ誘う
- 役割の分け方：YouTube は「入口・10〜20分でやさしく全体をつかむ」、アプリは「より詳しくマニアックな解説と、みんなとの議論」
- 概要欄のリンクは、その話題の記事へ直接つなぐ（2026-11-04 決定）。アプリが入っている人はアプリの記事がそのまま開く（ディープリンク）。入っていない人は記事の公開ページ（web-post）が開き、人気のコメントを見せて「この議論に参加しませんか？」でアプリへ誘う
- 中身の組み立て（2026-11-05 決定）：YouTube で 10〜20分の解説動画を出し、アプリの記事はそれをさらに深掘りする。動画は「分かりやすく全体をつかむ」、アプリは「より詳しく、マニアックに」（元データ、細かい数字、見方のちがい、過去との比較など）。記事の上には同じ YouTube 動画を置く
- チャンネル名：アプリと同じ **Halftick**（2026-11-05 決定）
- 言語：日本語と英語の両方で始める（2026-11-05 決定）
- 本数：不定期。ただし量はしっかり確保する。話題・ニュースが出た分だけ作る（2026-11-05 決定）
- 土台は動画、その解説をアプリで。アプリの配信は、最初は YouTube に上げた動画の深掘りに使う（2026-11-05 決定）

## 技術の前提
- バックエンド：Supabase の無料プランで始める（ログイン、データベース、チャットのリアルタイム通信、権限）（案）
  - 無料プランの上限（2026-11-03 公式の料金ページ）：データベース 500MB、月間利用者 5万人、ファイル 1GB、転送量 5GB、同時接続 200、リアルタイムのメッセージ 月200万件。1週間アクセスがないと一時停止。自動バックアップなし
  - 開発中は無料プラン、**公開するときに Pro（月25ドル〜）に上げる**（一時停止なし・毎日のバックアップあり）
- AI：**Claude API は使わない**（費用を抑えるため）。配信の下書きはオーナーが Claude の Max プラン（Claude Code）で作り、確認してから出す。サーバーが人を介さず AI を呼ぶことはしない
- 配信の作り方（案）：サーバーの定時処理が、公式データの数字（決まった文の型に当てはめる）とRSSの見出し＋リンクを材料として集める。オーナーはその材料と Max で作った下書きを管理画面で確認・編集して出す。出した配信はアプリ（プッシュ通知）とサイト（公開ページ）に同時に載る
- 情報源（案）：
  - 一次情報（主役）：EDINET API、e-Stat API、日銀・金融庁・財務省の発表、FRB、米労働統計局、SEC EDGAR、ECB、イングランド銀行、Eurostat、各社のIR
  - 経済全体に広げるための一次情報：内閣府（景気・GDP）、厚生労働省（賃金・雇用）、経済産業省・資源エネルギー庁（産業・電気とガス）、国土交通省（不動産価格）、総務省（物価・家計）、IMF・世界銀行・OECD（世界経済の見通し）
  - 報道：各媒体のRSS（見出し＋リンク＋事実だけの自前の短文。利用規約を媒体ごとに確認）
  - TDnet（適時開示）は JPX の利用規約を確認してから。商用は有料の配信サービスになる可能性
- 使うネイティブ機能：プッシュ通知（広告は「あとで」）
- → Expo Go で足りるか：いいえ（開発用ビルドが前提）
- EAS のプラン：無料（iOS ビルドの月の回数に注意）
- スタイルの書き方：theme のトークン＋StyleSheet
- いちばん不確かな部分：**議論が生まれて続くか**（配信の下で書きやすく読みやすい議論の形、返信の通知で人が戻ってくる流れ、リアルタイムでの表示、荒れない仕組み）。フェーズ5で最初に作り、少人数で試す。配信の材料集めはその次

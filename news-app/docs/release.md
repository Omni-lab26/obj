## 審査メモの5項目
1. アプリの目的と、誰が使うか
2. 主な機能と、それぞれの開き方
3. ログインが要るなら審査用アカウント（要らないならその旨）
4. ハードウェアや外部サービスに依存する機能の確かめ方
5. デモ動画の URL

## ストア入力の注意
- EAS Metadata は一部の欄で失敗することがある。手で入力する前提で進める
- 提出するビルドとコードの対応が分かるよう、提出時にタグを打つ

## 方向性
- トーン（3語）：**親しみやすい・知的・ライブ感**（ニュースの硬さより、仲間と話す温度。いま動いている感じ）
- 文言の声（2026-11-03 オーナー決定）：**ニュースらしく硬くしすぎず、ちょっとフレンドリーに。** です・ます調で、話しかけるように書く。例：「日銀は金利0.75%で据え置き。でも声明にちょっと変化あり」「あなたはどう思う？」「議論をのぞく」「人気順 / 新しい順」。くだけすぎ（タメ口・絵文字だらけ）にはしない。数字と事実は正確に
- 参考アプリ・作品と、どこを参考にするか（オーナーが送った参考画像より）：
  - Render（SNS）：最新のタイムラインの形（大きなサムネ・上の絞り込み・浮いたタブ）
  - Apple Podcasts：記事の全画面（上に絵、下に題名とボタン、下に浮かぶバー）、ライブラリとジャンルのページ
  - Apple Wallet のパス／会員カード：メンバーカード、記事の表紙1
  - 雑誌・ポスターの文字組み（明朝の大きな文字、紙の質感、計器のような情報帯）：サムネの型
  - NERV：速報の緊張感（赤い帯と、上から降りる知らせ）
  - 全体の操作部分は **Liquid Glass**（オーナー決定）
  - **bencho.dev**（https://bencho.dev/ ）：**雰囲気**を参考にする（オーナー指定）。1つひとつの部品が手に取れる「物」のようで、やわらかい灰色の地に白い角丸、少ない色、静かな文字。触ると気持ちよく反応する（切りかえがすべる、数字が回る、ピタッと止まる）。**部品はオリジナルで作る**（コードは写さない）
- シグネチャー（このアプリだけの形・言葉・動き。複数の画面で繰り返す）：
  1. **ハーフティックの印**：長い棒と、半分の長さの棒。ロゴ、アプリのアイコン、配信者の印、メンバーカードに使う
  2. **4本の目盛り**：1日4回の配信（7:00 / 11:30 / 15:30 / 22:00）を値動きの目盛りのように並べる。今の枠は長い棒、次の枠は短い棒（**ホームには出さない**。オーナー決定 2026-11-04。管理画面の「今日」で使う）
  3. **配信の番号**：HT-1104-3（11月4日の3本目）。サムネ、記事の表紙、管理画面で同じ番号を使う
  4. **アイコンから広がる動き**：プロフィールは、タップしたアイコンから丸く広がって出てくる
- 名前の由来と、それをどう形にするか：Halftick＝値動きの最小単位の半分（細かい動きまで見る）＋Halftime（合間の休憩）。**印は「長い棒＋半分の棒」**、言葉は「合間に、のぞく」

## トークン（実体は `theme/`。フェーズ3で作る）
### 色
暗い画面が基本。明るい画面は同じ役割で用意する（端末の設定に合わせる）。

| 役割 | 暗い画面 | 明るい画面 | 使う場所 |
| --- | --- | --- | --- |
| 地（bg） | `#111214` | `#F6F5F2` | 画面の背景 |
| 面（surface） | `#1C1D20` | `#FFFFFF` | カード、シート、設定のまとまり |
| 面2（surface2） | `#26272B` | `#EFEDE8` | 入力欄、小さなボタン、チップ |
| 線（line） | `#34363B` | `#E2DFD8` | 区切り線 |
| 文字（text） | `#F2F2F3` | `#16161A` | 本文、見出し |
| 補足（muted） | `#9A9CA3` | `#6B6A66` | 時刻、職種、補足 |
| **強調（accent）** | `#FF6A1A` | `#E8590C` | 送る・書く・グループを作るなど主な操作、未読の点、押した▲。**飾りには使わない** |
| リンク（link） | `#7CC0FF` | `#1F6FEB` | 「続きを読む」「すべて見る」 |
| よい（ok） | `#3DDC84` | `#1A9E55` | オンのスイッチ、✓ |
| **速報（alert）** | `#FF3B30` | `#E5372B` | 速報の帯・点・赤い線だけ。ほかに使わない |
| ひとこと（note） | `#2EC4B6` | `#0F9488` | 「ひとこと」の目印（左の線、引用符、点、ラベル）だけ |
| 深掘り（deep） | `#9B7BFF` | `#6A4FD6` | 「深掘り」の目印（左の線、表紙の帯、ラベル）だけ |
| ガラス（glass） | `rgba(28,28,32,.48)` | `rgba(255,255,255,.60)` | Liquid Glass の下地 |
| ガラスの縁 | `rgba(255,255,255,.20)` | `rgba(0,0,0,.08)` | ガラスの縁と光 |

- 記事とジャンルのページの地は、サムネの色を使わず **黒（ダーク）か白（ライト）** にする。ダークは `#000`、ライトは `#FFF`（ライトモードを出すときに作る）。サムネの色は画像の中だけに残す。戻るボタンと右上のボタンはスクロールしても動かさない（常に左上・右上）。サムネと地の境目は線を見せず、下へいくほど強くなるぼかしと、地の色へのなめらかなフェードでつなぐ

### 余白・角丸・影
| 種類 | 決めたこと |
| --- | --- |
| 余白 | 4 の倍数（4 / 8 / 12 / 16 / 20 / 24 / 32）。画面の左右は 16、記事の本文は 18 |
| 角丸 | ボタン・チップ・入力欄・タブ：丸（カプセル） / カード：18 / サムネ：22 / 小さなサムネ：10–14 / シートの上：28 / グループのアイコン：14（人は丸） |
| 影 | カードには影を付けない（面の色で分ける）。浮いているもの（タブ、浮いたボタン、シート、メンバーカード）だけに影 |

### Liquid Glass の使い方
- **使う**：下のタブ、検索の丸ボタン、絵の上に乗るボタン（戻る・保存・共有）、記事の下のコメントバー、シート、上に出る小さなお知らせ、速報の知らせ、右下の浮いたボタン
- **使わない**：カード、本文、コメント、リストなどの中身。中身は読みやすさを優先して面の色で置く
- iOS 26 以降は OS の Liquid Glass の部品を使い、それより前の iOS と Android は「ぼかし＋半透明＋縁の光」で近づける（使う部品は**未確認**。フェーズ3で Expo の公式ドキュメントで確かめる）
- ガラスの下が明るい絵でも文字が読めるよう、ガラスは少し暗くする（暗い画面で 48%）

### 動き
| 場面 | 長さ | 動き方 |
| --- | --- | --- |
| ボタン・切り替え | 200ms | すぐ反応 |
| シート（コメント欄など） | 320ms | ばねのように止まる。半分 → 全体 → 閉じる |
| 記事を開く | 350ms | 下から全画面 |
| プロフィール | 500ms | タップしたアイコンから丸く広がる。中身は少し遅れて浮かぶ |
| 速報の知らせ | 450ms | 上から降りて、5秒で戻る |
| 動きを減らす設定 | − | 広がる・降りる動きをやめ、ふわっと出るだけにする |
- 振動：▲を押す（軽く）、保存（成功）、配信を出す（中くらい）

### アイコン
- 線のアイコン 1 種類で統一（線の太さ 1.8）。セットはフェーズ3で決める（候補：Lucide。iOS は SF Symbols も検討。**未確認**）
- 人のアイコンは写真かサンプルの画像。グループは角丸の四角。**頭文字の丸や単色は使わない**（オーナー決定）
- アプリのアイコン（案）：①黒地に**オレンジのハーフティックの印** ②虹色のグラデーション（ミント→ラベンダー→ピーチ）に黒い印。`design-board.png` で比べる

## 投稿の種類の見分け方（2026-11-04 オーナー決定）
- 形・色・内容で分ける。**定時配信**＝正方形のサムネと「定時」のラベル／**速報**＝赤い線と帯／**ひとこと**＝絵なし、青緑の枠の中に大きめの文字と引用符／**深掘り**＝紫の線、横長の表紙に「読む時間」／**ユーザーの投稿**＝「みんな」だけに出し、本人のアイコンと名前が先頭（色の目印なし）
- 種類の色は目印にだけ使い、ボタンや飾りには使わない

## 記事の中の部品（2026-11-04。bencho.dev の雰囲気でオリジナル）
- 暗い記事の中に、**明るい「物」として置く**（地 `#F3F2EF`、中の面は白、角丸 24、影は少し）。色は黒・灰・オレンジだけ
- 右上に小さな英字のラベル（KEY NUMBER / SWITCH / VOTE / TAP / TRY）で、何ができるかを示す
| 部品 | 中身 | 触ると |
| --- | --- | --- |
| 大きな数字 | 記事のいちばん大事な数字（例：0.75%、+300円） | 見えたときに数字が回って止まる |
| くらべる | 前と今の文章・家計など | 切りかえのつまみがすべり、変わったところが色で出る |
| これからの流れ | 日付と出来事を縦に | ▶で順に光る |
| みんなの予想 | 2〜3択の質問 | 答えると結果の棒が伸びる。理由をコメントへ（議論につなげる） |
| 積み上げグラフ | 中身の内訳 | 棒をタップすると数字が出る |
| あなたの場合（試算） | 使用量・借入額などをスライダーで | 自分の場合の金額がその場で出る |
| 地域の色分け | 地域×月の表を色の濃さで | マスをタップすると数字が出る |
| ポイントのカード | 3枚のカード | タップで次のカードが前に来る |
| 線のグラフ（参考：Pull） | 日経平均・ドル円などの動き。1日 / 1週 / 1か月 | 線を指でなぞると、その時の値と時刻が出る。離すと今の値に戻る |
| 細い積み上げ棒（参考：Stacked bars） | 20日・12か月などの毎日・毎月の中身 | 棒の上をなぞると、上の大きな数字と内訳が変わる |
| 両替（参考：Asset swap） | 円とドルの両替の目安 | 金額を打つとすぐ計算。真ん中のボタンで払う方と受け取る方が入れかわる |
| 見通しの比較（参考：Image compare） | 前と今のグラフを重ねる（左＝前は灰色、右＝今は黒とオレンジ） | つまみを左右にドラッグ |
| 時代のアコーディオン（参考：Image accordion） | 年ごとの絵と短い説明 | タップした時代が広がる |
| あわせて読みたい（参考：Carousel） | 記事の一番下に、ほかの記事を扇のように重ねて | 左右にはじく。真ん中をタップで開く |
- 数字は材料（公式データ）から入れる。試算は「目安」と書く
- **グラフ・図の背景に色を付けない**（2026-11-04 オーナー決定）：ぼかしと薄い縁だけのガラスにして、記事の地が透けて見えるようにする。文字は白、線や棒は白の濃淡とオレンジ
- **読みごたえのある長さ**（2026-11-04 オーナー決定）：1本 2,000〜3,500字を目安。流れは「何が起きた → なぜ → どう受け止められた → 暮らしへの影響 → 見方のちがい → よくある疑問 → 用語メモ → Halftick のひとこと → みんなの予想」。題名の下に読む時間を出す
- **文章が主役、部品は脇役**（2026-11-04 オーナー決定）：本文は小見出しで区切って読みごたえを出し、グラフや図はコンパクトに（高さを抑え、文字も小さめ）。部品は本文の説明を「見て確かめる」ためのもの

## サムネの型（2026-11-03 案）
- 1日4回の配信ごとに絵を用意しなくてよいよう、**型に「大きな文字」と「英字」を入れるだけでサムネができる**ようにする。オーナーが送った参考の雰囲気（大きな文字・紙の質感・光・計器）を自前で描く
- 型：**紙面**（生成りの紙・太い明朝・朱色の波・落款）／**計器**（濃紺・縦書き・朱の斜め帯・照準・型番）／**光**（濃い青に光の帯・明朝）／**墨**（黒地に一筋の光・縦書き）。どれも粒子の質感をかける
- 右下か左下に配信の番号（例：HT-1104-4）。写真を使うこともできる
- 速報は「計器」を基本にする（NERVの緊張感）

## 禁止事項
- 絵文字をアイコンとして使う（ワイヤーの 🔥💬 は本番で線のアイコンに置きかえる）
- 画面の部品にグラデーションを使う（グラデーションはサムネとアプリのアイコンだけ）
- 強調の色を2つ以上使う。オレンジを飾りに使う。赤を速報以外に使う
- 中身（カード・本文）にガラスを使う。全部のカードに同じ影を付ける
- 頭文字の丸アバター、単色のアイコン
- 本文を中央ぞろえにする
- 他の人の作品の画像を使う（参考画像はワイヤーだけ）
